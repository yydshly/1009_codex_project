# 首次出场取证记录

在当前 Windows / Node 22.15.0 环境执行原始 `shoot.mjs --record --entry`：第一次仅得到相同的三张早期帧，MP4 经 ffprobe 校验只有 0.033333 秒，不能作为完整出场动画证据；第二次将 hold 增至 4500ms 后报告“录屏没有拿到画面”。保留原始文件便于复查，不在网页中当作可用录像展示。

首次出场动画已由 `../motion/report.json` 检测到，但独立出场录屏证据仍有缺口。项目切换与保存录像经 ffprobe 分别确认为 1.6s 与 1.733333s，配合三帧和浏览器交互使用。
