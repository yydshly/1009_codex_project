01

库的能力是什么？

原作能力

自由漫游鼠标 + WASD，跑步、碰撞与台阶

空间注释按 E 读取预设翻译与文化背景

球面世界近景行走与小行星远景

色带：把光照压成明暗档位MeshToonMaterial + DataTexture。不同法线方向形成整块明暗。
描边：从深度变化提取轮廓使用深度二阶差分，凹角较轻、远处减弱；重要物件另加背面外壳。
调色：建立冷影与暖光关系控制饱和度、暖度、暗部抬升与暗角；负责 linear → sRGB 输出。

雾在场景阶段处理；色带与阴影偏色的 Shader 补丁依赖 Three.js 版本。造型与构图仍是最终风格的重要输入。

04

世界怎样搭建？

代码生成部件 · 作者编排世界

① 基础积木

盒体、圆柱、管道、曲线、贴图平面

② 参数化部件

窗户重复、树冠种子、Canvas2D 文字

③ 人工布局

物件坐标、初始镜头、地点叙事

④ 运行数据

碰撞体、高度面、热点、更新回调

⑤ 球面投影

平面 XZ 映射到球面，动画保留局部坐标

Batch 合并静态几何；InstancedMesh 复用树冠。核心世界不依赖预制 glTF。种子使局部差异可复现。

玩家碰撞与高度查询仍在平面 XZ；相机显示球面位置和方向。改布局时需同步碰撞、热点与镜头。

05

我们已完成的实际扩展

本地验证

“柳荫里社区开放日” · 第一次到访社区

入口→活动公告→邻里书屋→树荫休息

新建几何：入口、书屋、公告板、步道、围栏与住宅。

真实交互：四站导览、地点点击、镜头定位、中英说明、漫游与设施互动。

风格实验：三套预设、2–5 档明暗、太阳高度、阴影色、描边、雾、杨絮。

参数复用：浏览器保存 + JSON 导出；当前没有 JSON 导入按钮。

社区名称、布局与活动为演示数据。现有场景复用了上游模块；风格参数保存不包含世界布局。

可复用的是哪些模块？

toon + palette统一材质、色带与配色

Pipeline深度描边、调色与抗锯齿

Batch + decal参数化建模与标牌

planet平面到球面的空间映射

nature树木、灌木与杨絮

yard + player设施动画、漫游与碰撞

地点数据 + 注释导览镜头、多语言内容

移植时同步碰撞、热点、相机、场景尺度与 Three.js 兼容；静态几何合并后修改部件通常需要重建批次。

可直接使用的最小场景提示词
独立创建 Three.js 庭院：地面 + 一栋住宅 + 三棵树 + 长椅 + 公告板；三档明暗，太阳约 30°，冷青阴影，细轮廓，轻雾。用 styleConfig 集中参数并实时调节；固定镜头、布局和种子，提交实际浏览器截图。
交给编程模型生成几何、渲染规则、参数面板与真实交互。
交给图像模型生成艺术方向参考图；后续 3D 工程仍需实现。

最小场景→模型实现→同镜头截图→单项修正→保存预设→扩展世界

提示词规定方向；描边、雾距离和暖度需按工程重新标定，实际结果以截图为准。

能力边界

轻量碰撞；桌面键鼠优先；翻译为预设内容；基线无完整物理、多人、任务系统与场景编辑器。需要 WebGL，尚无跨硬件性能保证。
