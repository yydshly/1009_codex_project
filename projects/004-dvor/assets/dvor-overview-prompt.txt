01 库的能力是什么？
自由漫游：鼠标、WASD、跑步、碰撞与台阶
空间注释：按 E 读取预设翻译与文化背景
环境互动：设施动画、杨絮、电车运行与停靠
球面世界：近景行走与小行星远景
视觉控制：卡通明暗、描边、冷暖与空气透视
边界：提供可改造源码，尚无通用场景编辑器。

02 能做出哪些效果？
手绘动画背景观感：明确体块、大块明暗、冷影暖光、细轮廓、远景层次、生活纹理。
六个已有样例标签：通道构图｜住宅立面｜游乐设施｜车库生活｜环线电车｜小行星
观感来自造型、配色、布局与渲染共同作用。

03 风格怎样渲染？
横向完整管线箭头：
几何与 Canvas 纹理 → 色带光照 + 阴影偏色 + 场景雾 → 颜色 / 深度纹理 → 深度描边 → 冷暖调色 → FXAA → 屏幕
旁边配三档明暗块和轮廓示意。
色带：MeshToonMaterial + DataTexture，把光照压成明暗档位。
描边：深度二阶差分提取轮廓；重要物件另加背面外壳。
调色：冷影、暖光、饱和度、暗部抬升与暗角；正确输出 sRGB。
雾在场景阶段处理。Shader 补丁依赖 Three.js 版本。

04 世界怎样搭建？
积木到星球的可视流程：
基础积木 → 参数化部件 → 人工布局 → 运行数据 → 球面投影
盒体、圆柱、管道、曲线组成建筑和生活物件。
窗户重复、树冠种子、Canvas2D 文字；坐标和镜头由作者编排。
运行数据包括碰撞体、高度面、热点、动画更新回调。
平面 XZ 映射到球面；行走碰撞查询仍在平面。
Batch 合并静态几何；InstancedMesh 复用树冠；核心世界不依赖预制 glTF。
小图展示平面庭院弯到球面：“R = 150；电车环线闭合。”

05 我们已完成的实际扩展
“第一次到访社区”：入口 → 活动公告 → 邻里书屋 → 树荫休息
新建几何：入口、书屋、公告板、步道、围栏与住宅
实际交互：四站导览、地点点击、镜头定位、中英说明、漫游、设施互动
风格实验：三套预设、2–5 档明暗、太阳高度、阴影色、描边、雾、杨絮
参数复用：浏览器保存 + JSON 导出
社区名称、布局与活动为演示数据；现有场景复用了上游模块。

06 可复用的是哪些模块？
toon + palette｜统一材质、色带与配色
Pipeline｜深度描边、调色与抗锯齿
Batch + decal｜参数化建模与标牌
planet｜平面到球面的空间映射
nature｜树木、灌木与杨絮
yard + player｜设施动画、漫游与碰撞
地点数据 + 注释｜导览镜头、多语言内容
移植时同步碰撞、热点、相机、场景尺度与 Three.js 兼容。

07 使用场景与可扩展方向（虚线框：建议）
场景推导：城市记忆与文化展览；社区 / 校园导览；语言学习与空间叙事；品牌体验与风格原型。
未来可扩展：真实场地数据、内容编辑、多语言与语音、任务进度、glTF 导入、布局编辑、触屏与无障碍、LOD、分区加载、性能分档。
以上为产品方向建议，不代表上游已经具备。

08 不参考原作，如何用提示词控制？
把审美要求写成可执行规格，再用实际截图校准。
七项规格标签：造型｜构图｜配色｜明暗｜灯光｜描边｜氛围
五个色块：建筑 #D9C39E｜植被 #90A85C｜阴影 #5B8087｜天空 #ECD3AB｜点缀 #B86D49
可直接使用的示例（放在突出的大文本框）：
“独立创建 Three.js 庭院：地面 + 一栋住宅 + 三棵树 + 长椅 + 公告板；三档明暗，太阳约 30°，冷青阴影，细轮廓，轻雾。用 styleConfig 集中参数并实时调节；固定镜头、布局和种子，提交实际浏览器截图。”
校准环路：最小场景 → 模型实现 → 同镜头截图 → 单项修正 → 保存预设 → 扩展世界
修正例：“保留镜头和布局，只抬亮暗部并改成蓝绿色；输出同镜头对比。”
编程模型：生成几何、渲染规则与真实交互。
图像模型：生成艺术方向参考图；后续 3D 工程仍需实现。
网页已提供两类完整模板、编辑 / 复制 / TXT 下载，以及当前实验参数带入。
提示词规定方向；描边、雾距离和暖度需按工程重新标定。
