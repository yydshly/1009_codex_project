01 / BUILD

搭建舞台资产

配置台面、屏幕占位、立柱、内容插槽和多个激光设备。屏幕当前只提供空间占位。

02 / SAVE

保存与复用

模板可修改后另存独立项目；保存更新当前项目版本。项目保存在当前浏览器，导出 JSON 可迁移。导出文件记录素材 ID，素材由使用方提供。

下载「极光环岛」对比布置 ↓，也可直接使用上方模板，在两个业务中选择同一项目。
