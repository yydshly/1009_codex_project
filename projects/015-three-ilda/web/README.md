# Three ILDA 中文实验台

纯前端 Vite 6.4.3 + Three.js r185 + three-ilda WebGL 2。上游源码固定在 `6044b91d120cc01f73bdaebed4f7e4d03feb0d2f`，保留版权、LICENSE、CREDITS，没有修改扫描器或渲染管线。

## 命令

```powershell
npm ci
npm run build       # 生成原创 .ild，输出 dist/
npm run dev         # http://127.0.0.1:5215/
npm run check       # 104 项 Node 用例，无排除
npm run preview     # http://127.0.0.1:5216/
```

Node.js 22+。首次开发前先执行 `npm run build` 或 `npm run samples`，确保样例可请求。运行不依赖 CDN、账户、API 或服务端。导入文件只在浏览器解析，不上传。

`/product.html#summary` 是当前阶段研究汇总入口：首屏展示实际三岛展台和初版光之花截图，可直接进入激光实验台、音乐演出、发布会和自动泵讲解。`#understanding` 保留阶段结论，后续内容为组件 / 舞台 / 业务的分工、五步按需使用流程、三个复用示例与验证边界。早期扩展设想保留在可展开的讨论备忘录中。页面链接的五张原始截图和五份验证记录由 `samples` 复制到 `public/records/`，随构建产物在编号子路径交付；图注注明实际截图和日期。实验台首页的汇总入口也展示同一张展台图。

`/product.html#overview` 增加一图总览：激光组件价值、舞台与业务分工、真实效果、三种已接入业务、16 类 / 64 个探索设想、商业路径与技术边界。支持查看独立矢量原图和下载 1920 × 3780 高清 PNG / SVG，两份文件也由 `samples` 原样交付到 `records/`；当前共十二个记录文件。生成源为 `scripts/generate-overview.mjs`，仅用 Node 可重新生成自包含 SVG；可选 `--sharp-module <本地 sharp 入口> --font-file <中文字体>` 生成配套 PNG，网页运行和常规构建不需要 sharp 或本机字体文件。

原始路线由本地 LineSegments 显示文件目标点，节目时钟仍跟随扫描点率；其余模式调用真实上游组件。二维对照直接使用同一个 scanner 的目标帧和 snapshot。

ILDA 编码、原创样例、下载与对照界面属于本项目新增功能。四组原创 `.ild` 位于 `public/shows/`，18 个上游文件位于 `public/upstream/ilda/`；合并目录 `public/shows/catalog.json` 记录来源、原文件名、帧数、点数、轨道和 SHA-256。构建不依赖被忽略的 upstream 克隆。

默认开启自动轮播，从目录第 1 项 0HNY 的第 1 帧第 1 个点开始，每个节目完整播放一遍后切换，全部 22 个播完后从头循环。画布上方可以停止/开启轮播，并查看当前帧和下一节目。列表筛选不改变轮播顺序。手动选择节目后，从新节目的第 1 帧完整播放；导入本地文件会关闭轮播，文件读取失败也会停止轮播。重新开启轮播会从当前节目第 1 帧重播。

暂停播放或切到后台时保留播放进度；恢复后继续。拖动帧滑杆会暂停并显示所选整帧，继续播放时从该位置播到片尾。异步加载期间不推进旧节目、不重复请求。完成判断使用当前轨道的真实扫描样本数，点率影响速度；最后一次 update 限制在最后一个点，先提交片尾画面再加载下一项，避免同一显示帧又绕回第 1 帧。重播和换轨使用 show.reset()，不会预扫描后跳过第 1 帧。

也可在画布上方手动选择全部 22 个节目，用左右箭头依次切换。下方效果列表支持来源筛选与文件名搜索；点击缩略图加载真实节目后回到画布，从第 1 帧播放。缩略图使用上游 catalog 的 previewFrame，播放使用 track，沿用 Sylvester 的 observable-demo 配色。

点击「保存画面」会冻结当前画面为 PNG，随后点击旁边出现的「下载 PNG」获取文件；动画继续播放。

## 产品记录、舞台搭建与独立业务

`/product.html` 保存能力与价值、舞台搭建与复用、下游虚拟演出、AI / 音乐纪念方向，以及待验证的商业模式。用户明确舞台搭建与演出属于不同层，因此当前重点转为交付可复用舞台资产。参考来源链接随记录保留；没有把设想写成已上线能力。

`/stage.html` 是舞台搭建器。可添加与删除五类构件，通过坐标轴拖动或属性面板设置位置、尺寸、朝向和颜色；设备可设置投影面、局部出光口、点率、亮度与 22 个预览节目。当前屏幕只提供几何占位，内容插槽留给其他业务。最多 24 个构件，坐标是场景单位，不代表工程校准。光效预览可以独立暂停，不使用歌曲或演出时间线。

点击保存后写入同站点 localStorage；导出 / 导入 JSON 可迁移配置。导入先验证版本、类型、ID、坐标与尺寸、设备参数和素材 ID，失败时保留当前布置。素材不打包进 JSON，使用方须提供对应素材库。存储受限时提示原因，仍可导出。

`/show.html` 是独立业务示例，读取同一份已保存配置，没有保存时使用默认舞台。台面、屏幕、设备位置 / 尺寸 / 出光口与点率沿用配置；演出按接入方式沿用展台节目或使用业务编排，再加入音乐、背景、粒子、镜头与互动；在第一个内容插槽放入抽象雕塑。保存所选项目或切换舞台后，演出页自动重新装配并暂停音乐，也可点击「重新读取项目」。90 秒原创电子配乐驱动开场（0–10）、主歌（10–30）、副歌（30–50）、间奏（50–70）和结束（70–90 秒）。应援只影响当前浏览器。

以 AudioContext.currentTime 为主时钟。普通播放补算扫描差值，跳段或回退时从所选段落重新扫描到目标时间，确保多个 show 同步。静音不会停止时钟；暂停冻结音乐与段落时间，隐藏页面会主动暂停，返回后由用户继续。配乐在构建时生成，非 AI 合成歌声，不含第三方采样、歌曲或人物形象；按本项目原创内容许可提供。

### 产品发布会接入示例

`/launch.html` 与音乐示例使用同一个项目选择模块、同一个 `StageLayout` 装配器。空间和设备仍来自配置；发布会按接入方式沿用展台效果或从自己的脚本选择原创光效，在第一个内容插槽挂载原创概念声场装置，为已有屏幕挂载 CanvasTexture 文案平面。产品和屏幕继承插槽 / 屏幕构件的位置与朝向，配置本身不变。不存在插槽或屏幕时，保留舞台并说明缺少什么，不自行增加构件。

60 秒流程分为预热（0–8）、揭幕（8–24）、结构（24–44）和场景（44–60）。基于 performance.now 的业务时钟支持暂停、跳段、重播和片尾；页面切后台暂停，不补算隐藏时间。默认自动演示；偏好减少动态效果的浏览器默认暂停。可手动切换近景、俯视、产品配色与结构展示，名称和发布文案即时同步到页面和舞台屏幕。产品建模和流程都是本地新增，概念文案不代表真实商品规格。未接入视频、销售、音频或模型上传。

重新读取配置会释放旧业务资源，再装配当前已保存舞台，保留本次产品名称与配色。业务内容不写回配置，不依赖音乐示例的音频与演出时间线。浏览器实际检查已覆盖默认舞台的三维画面、暂停、阶段、近景、结构展开、配色与文案编辑；跨业务使用任意保存配置由 Node 的两个真实装配器用例验证。

`public/stages/aurora-island.json` 保存“极光环岛 · 四机双屏”的完整 11 构件配置：18×11 椭圆台面、左侧抬高内容台、两面独立屏幕、两根立柱、一个偏置内容插槽、四台不同朝向 / 点率的激光设备。舞台协议、默认舞台和业务脚本保持兼容。在搭建器导入此文件并保存，刷新音乐页、点击发布会“重新读取舞台”即可比较。浏览器已实测导入 / 保存 / 刷新 / 导出，并取得两种业务的实际画面；导出的 JSON 与该文件逐字段相同。证据见 `../assets/stage-reuse-validation.json`。这次没有逐项检查拖动、全屏、视频、音频听感或全部 22 素材。

### 舞台方案库与独立项目

搭建器新增五套模板：极光环岛（11 构件 / 四机双屏）、镜幕发布厅（9 构件 / 宽幅屏与台阶）、星轨 T 型秀场（18 构件 / 走台与两侧座席）、三岛环绕展厅（12 构件 / 三个展岛与三屏）、双区直播间（10 构件 / 主播桌与商品台）。卡片图片为从配置绘制的平面示意，三维编辑画布使用真实装配器。

模板提供只读起点，编辑后「创建项目」或「另存为新项目」生成独立 ID；另存保留原项目，重复名称自动增加副本序号。「我的项目」重新打开已保存方案；「保存项目」保持 ID 并递增版本。旧单舞台保留为 project-legacy，原存储键不删除。最多 64 个本地项目，可继续导出单舞台 JSON 迁移；导入生成未保存草稿。切换前如有未保存修改会提示。

方案库独立存储在 three-ilda:stage-projects:v1，包含 active 引用和 projects；每个项目持有 version-1 舞台配置、版本、更新时间与模板来源，不含业务时间线。音乐与发布会使用相同模块解析所选引用；跨页 storage 事件同步选择与已保存版本。编辑草稿不写回其他业务。音乐重装配时暂停音频、保留播放位置并释放旧内容；发布会切换后从开场暂停待播放。新增镜头拟合按台面边界取景，构件资源正常释放。项目仍局限于同一浏览器、同一站点，尚未实现云端分享或协作。

7 项新增 Node 用例验证模板 / 项目隔离、旧配置迁移、版本与共享选择、输入及存储失败、旋转台面的边界拟合，以及五套项目被两种真实装配器加载并运行不同业务脚本。实际浏览器操作与截图见 ../assets/stage-library-validation.json。

### 舞台资产与接入接口

新增效果接入流程：在 `/stage.html` 的“把效果接入展台”中选全部或指定激光设备，再点击 22 个效果卡片。卡片是源帧路线示意，真实效果由画布播放；接入成功会自动选择“沿用展台效果”，修改后保存或另存。设备属性里的“展台效果”也使用同一目录。沿用模式下，音乐与发布会保持保存的节目、点率、轨迹 / 光束亮度、设备布置，不按业务段落替换光效；暂停和跳转跟随各业务时钟。选择“跟随业务编排”后保存，可恢复原有音乐 / 发布会脚本的光效。两页显示实际光效来源。

协议新增可选 `effectMode: "stage" | "business"`，仍使用 version 1；旧配置缺省继续业务编排，旧文件往返不强行增加字段。导出 JSON 同时保留 `effectMode` 与各设备 `program`，独立项目及版本同步仍沿用原方案库。`public/stages/exhibition-effects.json` 是通过 UI 保存并实际导出的三岛展台示例，DOLPHIN 与 PLASMA2 分别绑定两台设备。效果文件来自已保留来源与许可的既有目录，不复制到配置中。

效果接入这一轮新增 6 项用例后合计 84 项 Node 测试。全部 22 个素材由共同加载器与真实扫描器测试；浏览器实际效果与交互检查覆盖示例的 DOLPHIN / PLASMA2，详见 `../assets/stage-effects-validation.json`，不表示每个素材已在各舞台逐一 GPU 验证。

### 编辑流程完善

效果库可按中英文名称 / 素材 ID 搜索，按上游 / 本地原创筛选，显示匹配数量、空结果与源文件帧数。帧数不等于播放秒数，扫描速度由设备点率决定。接入方式下方会说明当前业务使用已保存效果还是业务编排。

配置编辑支持最多 60 步撤销 / 重做。连续属性输入与一次拖动合并，换效果、增删构件、主题、名称和恢复默认也纳入历史；保存后保留历史，按配置内容判断是否回到保存点。打开其他项目 / 模板、导入或刷新会建立新的历史。快捷键为 Ctrl / ⌘ + Z、Shift + Z、S，Shift + S 另存；文本输入中的撤销保留浏览器行为。页面有未保存修改时，关闭或刷新由浏览器提示。

多编辑页的项目列表显示画布实际版本；检测到相同项目更新时提示读取最新或另存，不自动覆盖本页草稿。保存传入 expectedRevision 并在存储前核对版本；旧版本保存失败不写入。该机制用于同站点浏览器项目库，不属于云端多人事务。导出前会提交属性与名称，无变化的保存不增加版本。

新增 6 项编辑流程测试，这一轮共 90 项通过。浏览器实测搜索、筛选、换效果与删除恢复、连续调参撤销、保存后的历史、双页版本更新提示和两业务自动读取；详见 `../assets/stage-editor-validation.json`。

JSON 协议为 `kind: "ilda-virtual-stage"` / `version: 1`，包含名称、背景和 `objects` 数组。构件记录稳定 ID、类型、名称、位置 `[x,y,z]`、尺寸 `[宽,高,深]`、绕 Y 轴朝向（度）和颜色；台面额外记录形状，激光设备额外记录节目 ID、相对投影面的出光口、点率和亮度。激光投影只使用宽 / 高，深度字段保留为占位。素材 ID 由受信任的 22 项目录解析，不从配置获取任意 URL。

业务从文件或存储读取 JSON，先调用 `validateStage`，再用 `StageLayout` 装配。旧单舞台保存键为 `three-ilda:stage-layout:v1`；方案库现在使用 `three-ilda:stage-projects:v1`，每个站点来源保存各自的项目；配置不含音频、人物与时间线。普通 Three.js 对象可以挂到 `layout.records.get(id).root` 内容插槽下，激光通过 `layout.setProgram(id, parsedAsset)` 更换数据，通过 `layout.shows` 统一控制扫描时间。管线、renderer、scene 和 camera 由使用方提供，业务结束时释放资源。

```js
import { validateStage } from './src/stage-definition.js';
import { StageLayout } from './src/stage-layout.js';
const definition = validateStage(JSON.parse(configText));
const layout = new StageLayout(scene, pipeline, { showSlots: false });
layout.build(definition);
const slot = definition.objects.find(object => object.type === 'slot');
if (slot) layout.records.get(slot.id).root.add(contentObject);
// 音乐、角色、编排与同步由当前业务实现。
// 业务退出时：layout.dispose(); pipeline.dispose(); renderer.dispose();
```

这些编辑和资产接口属于本项目新增能力，上游源码和许可保持原样。

## 边界

- WebGL 2 光效需要浮点颜色缓冲；不支持时显示具体错误。
- 扫描器忽略文件 Z；图案位于局部 XY 平面。
- 遮挡是相机深度比较，没有从出光口做光路求交。
- 点率改变扫描与节目速度；暂停同时冻结余辉。实验台把 dt 限制到 0.05 秒；演出示例使用音频主时钟，隐藏页面后暂停，跳段时重新对齐扫描时间。
- 舞台搭建器支持本地保存与 JSON 复用；云端协作、视频屏幕、人物、AI、多人业务和物理光学仿真仍需另外实现。
- 采用深色场景和线性输出；截图与 FPS 是当前设备状态，不是性能保证。
