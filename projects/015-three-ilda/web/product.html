HOW IT WORKS / DATA → SCAN → LIGHT

一串坐标，为什么能成为激光效果？

  1. 01 / 数据

    文件决定画什么

    ILDA 点记录描述目标位置、颜色、扫描顺序、关光跳转和帧。18 份上游节目提供现成图案与动画；4 份本地样例由程序生成 format 5 点记录。歌手、音乐、模型、烟雾贴图和舞台布局不在文件里。

  2. 02 / 扫描

    固定点率计算运动

    每次经过 dt 秒，补算 dt × pointRate 个点并保留小数。X/Y 两轴按速度与位置递推追赶目标，形成滞后、圆角或振荡。点率同时影响节目速度；N 点帧的时间为 N / pointRate 秒，与显示器 FPS 不同。

    速度 = (旧速度 + (目标位置 − 当前位置) × gain) × dampening
位置 = 当前位置 + 速度

    dampening 是保留速度的比例，值越大，阻尼越弱。该模型未描述具体设备的电机、驱动器或校准误差。

  3. 03 / 历史

    关光移动，旧光渐暗

    关光点仍推动位置，但显示颜色归零，避免连接不相邻图形。blankingOffset 偏移开关标记以近似补偿延迟。环形缓冲保留近期样本，颜色按 lightDecay^(年龄秒数 × 60) 衰减；容量限制可见历史长度。

  4. 04 / GPU

    轨迹与出光口组成画面

    CPU 整理相邻发光样本为线段，线段和出光口组成三角面；GPU 加入颜色、三维噪声、亮度包络、深度衰减，后处理合成辉光与柔和光束。雾光由着色器绘制，是实时视觉效果。

  5. 05 / 应用

    配置布置，业务驱动内容

    加载舞台 JSON → StageLayout 装配空间与设备 → 业务将模型放入插槽、文案送入屏幕 → 自己的时钟推进激光、模型、镜头和音频。音乐、发布会、泵讲解共享布置，保留独立的内容流程。

轨迹当前输出 Z = 0，虽然 ILDA 可包含三维坐标；光束遮挡依赖观察相机深度，并非从激光出光口计算的物理光路。网页效果可用于呈现与机制学习，不能据此推断实物设备的安全区域、照度或投影精度。

02 / USE IT WHEN A SCENE IS NEEDED

后续按这个流程使用。

  1. 01

    先明确内容和场景

    确定面向谁、讲什么、需要哪些模型 / 屏幕 / 演员，以及观看和交互方式。

  2. 02

    从五套模板搭建舞台

    按场景调整布置、内容插槽、设备位置与参数，把需要的激光节目绑定到设备。

  3. 03

    另存项目并导出配置

    保留模板和原方案，建立独立舞台项目；需要迁移到另一浏览器或交付时，导出 JSON。

  4. 04

    由业务接入内容

    选择同一舞台，将模型挂入内容插槽、文案送入屏幕，由业务安排镜头、音频、动作和时间线。

  5. 05

    实际预览，再按需求补能力

    检查完整流程、画面、交互与目标设备性能；只有出现具体需求时，再加入云端分享、协作、人物、AI 或硬件输出。

本地项目保存在同一浏览器、同一站点下。需要长期保留或迁移时导出 JSON；配置记录舞台与素材 ID，模型、音频、角色等业务素材仍需一同准备。

VALUE / FROM COMPONENT TO REUSABLE WORK

库的价值，和我们可以继续做的产品。

开发者价值 / 已有实现

把激光显示封装成组件

省去 ILDA 二进制解析、分轨、固定频率扫描、关光与历史缓冲、几何上传、材质和后处理的重复工作。场景对象、参数及资源生命周期可由应用控制，适合浏览器视觉预览、教学和三维空间。

我们的产品基础 / 已有原型

舞台成为可反复使用的资产

模板 → 编辑 → 独立项目 → 效果绑定 → 多业务读取，形成可保存的布置。空间投入与内容制作分开，同一配置承载音乐、品牌或教学；接入 002 模型说明以前研究过的三维内容也能组合。

使用方价值 / 待真实项目衡量

让方案具体、内容可体验

客户可看到实际空间与效果，团队可比较布置，观众可交互查看结构或跟随完整介绍。沟通效率、观看完成率、教学效果与商业转化需要真实项目评估，目前没有量化收益。

可探索制作工具订阅、模板与素材许可、品牌活动与产品展台交付、教学内容包、定制场景服务和集成支持。先围绕一类用户完成完整交付，记录搭建耗时、修改次数、素材成本、性能、观看行为及实际付费反馈，再决定产品化范围。

舞台回答“在哪里呈现、用什么设备和插槽”；业务回答“讲什么、怎么讲、何时变化”。唱歌、二人转、讲义、皮影戏、AI 演唱会或产品教学各自需要内容团队与业务实现。当前无需为了继续研究一次性补齐所有方向。

01 / WHAT THE LIBRARY PROVIDES

能力与价值：可控制的激光显示组件

ILDA 文件存储坐标、颜色与关光指令。three-ilda 解析这些数据，计算简化振镜运动，维护扫描历史，再绘制轨迹、辉光和空气光束。浏览器里的画面由数据实时生成。

源码核对 / 已验证

库提供什么

  • ILDA 解析、调色板与投影设备分轨。
  • 按点率推进的扫描模拟、残影与关光跳转。
  • 可嵌入 Three.js 的场景对象与 WebGL / WebGPU 光效实现。
  • 位置、尺寸、亮度、光束等参数可由程序控制。
本项目新增 / 已实现

实验台提供什么

  • 18 个上游节目与 4 个原创样例，共 22 个。
  • 三个显示阶段、调参、导入下载、路线对照。
  • 每个节目从第 1 帧完整播放一次，全部播完再循环。
  • 节目列表、搜索筛选、轮播与研究界面。
  • 本地舞台搭建、构件编辑、保存与 JSON 导入导出。
明确边界

扩展时需要补什么

  • 节目编辑、音乐时间线、人物动画与 AI 生成。
  • 多人同步、账号、云端项目、分享和评论。
  • 真实设备输出与工程光学仿真。
  • WebGPU 的 GPU 行为尚未在本项目实测。

这里的场景首先指网页中的虚拟三维场景，普通电脑即可体验。当前扫描轨迹位于二维平面，光束与遮挡采用视觉近似；节目素材需要另行提供。当前产品方向是搭建可复用的舞台空间，演出内容通过独立业务接入。舞台搭建器是本项目用 Three.js 新增的工具，three-ilda 本身仅负责其中的激光显示。

03 / A VIRTUAL MUSIC EXPERIENCE

舞台里可以发生什么？

搭建器先交付舞台空间、设备和内容插槽。音乐演出、品牌发布会、展览与 AI 角色体验是使用舞台的下游业务。原来的 90 秒演出已保留为独立接入示例 ↗，用于说明如何读取舞台配置并运行自己的编排。

下面的五段结构是音乐演出业务的一个设想，不属于舞台搭建器的必要能力；歌词、歌手、影像与多人应援仍需另外实现。

  1. 01 / 开场

    进入光的空间

    从暗场逐渐点亮舞台、光线通道与远处轮廓。

  2. 02 / 主歌

    靠近音乐情绪

    柔和扫描和缓慢运动；后续可加入歌词、回忆画面。

  3. 03 / 副歌

    让舞台展开

    多台激光、节奏脉冲与粒子共同变化，应援影响现场视觉。

  4. 04 / 间奏

    切换意境

    在星海与霓虹城市等主题之间切换镜头和空间氛围。

  5. 05 / 结束

    留下参与痕迹

    光线收束；后续可将留言组织成图案或生成分享画面。

three-ilda

激光组件层

解析与扫描 ILDA，提供轨迹、残影、辉光和空气光束。它可以嵌入任意 Three.js 场景。

本项目 / 当前能力

舞台搭建层

配置空间、台面、屏幕占位、设备和内容插槽，把已有节目绑定设备，连同空间与参数保存为独立 JSON。音乐与发布会可沿用展台效果，或使用自己的编排；泵讲解直接使用设备绑定。

独立业务 / 示例与设想

演出与内容层

读取舞台，再接入音乐、人物、时间线、AI 与互动。90 秒音乐示例负责音频与应援；60 秒发布会示例负责产品、屏幕文案与结构展示。108 秒泵讲解负责六部件教学。三种业务复用同一份舞台配置。
