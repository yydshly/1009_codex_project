# 本地演示制作 Brief

- 真实场景：维护本仓库 GitHub 项目研究总库；收藏项目后，需要编号目录、研究依据和独立 Web 演示。
- 观众：准备研究和收录开源项目的维护者。
- 唯一行动：打开 001-motion-video-kit 研究页，开始理解与复现。
- 可证明事实：根脚本 project:new 自动分配编号；项目固定目录为 README.md、research.md、assets/、web/；projects.json 维护 sourceRef；pages:build 汇总独立编号路径。
- 内容来源：本仓库 scripts/repo.mjs、AGENTS.md、projects.json；上游 commit 255562b04b1e5ecaa4ba98e5c9aa191d5ba7f6fa。
- 输出：24 秒、16:9、1280×720、30fps 的 HTML/GSAP 动画，以及 HyperFrames 实际渲染的 MP4。演示无配乐。
- 风格：深蓝 / 荧光黄绿 / 紫色；一个项目卡片贯穿镜头，命令产生目录，证据记录产生研究页。
- 素材：原创 HTML、CSS、SVG 与真实文本；不用第三方影片、图片、字体文件，不调用生成模型。
- 标注：真实仓库流程，界面为说明性绘制；动画不执行创建或发布操作。
- 不得宣称：已经线上发布、广告转化提升、上游完整案例已复现、这是上游原始视频或网页截图。
