## 完整理解

### 定位

连接创意、参考媒体、生成任务、助手操作与剪辑成片的本地 AI 视频工作台；无限画布承载创作上下文。

### 入口与出口

手动桌面界面、内置 Pi 与外部 MCP/CLI；输入文案/提示词、图片/视频/音频参考、模型渠道与参数，输出生成素材、可播放下载的视频、可编辑工作区和操作/任务记录。

### 能力

多模态生成、画布与资产组织、分镜及批量任务、Pi 业务工具、媒体工具/时间线/字幕/FFmpeg 导出、渠道和自动化接入；生成画质由具体模型决定。

### 模块

按职责归纳画布、项目与资产、模型目录与协议、异步任务、Pi 与 Skills、受控操作层、媒体工具与剪辑、插件接缝八类；该分类为研究归纳。

### 原理

React/Wails → Go 本地 API → SQLite/资源目录；模型合同校验 → 创建/轮询/下载；Pi 工具由 Go 做权限、版本、幂等与撤销；统一剪辑计划分别交给 native/wasm FFmpeg 执行。

### 效果与证据

完整原全景图引导；本页验证三场景、五步骤、15 秒分镜示意与三入口切换，流程卡为说明文件。维护者记录候选版 4 图/8 视频与 15 秒阅读成片两版；本研究未复跑桌面或付费生成。

### 场景

品牌广告与产品展示、短剧和视觉分镜预演、知识/阅读倡议、多模型与 Agent 实验、素材复用和迭代交付。

### 价值

上下文与结果关系可见、生成到剪辑连续、人工与助手协作、模型可替换、资产状态可追踪、职责分工可研究；未量化效率、ROI 或商业转化。

### 扩展

行业模板与品牌约束、新模型合同和适配器、精细声音/剪辑、质量评测与素材选择、可恢复自动化、团队同步与共享资产；列明现有接入点、开发内容和验收目标。

### 边界

默认单用户本地工作区，生成可能向供应商发送参考且收费；工具非任意 shell，模型发现不等于生成验证；VERSION v1.7.14 的发行状态在固定验收中未完成；高级合成、团队协作与端到端性能需另验。

## 从文案或图片，到视频交付

1. 整理主题、文案与参考媒体，建立节点和引用关系。
2. 设计分镜，可手动组织，也可让 Pi 读取上下文建立草稿。
3. 选择渠道及模型，检查输入合同，配置参数；提交后由后端创建、轮询、下载和回收结果。
4. 将可用结果进入时间线，设置顺序、裁切、声音、字幕、淡入淡出与输出规格。
5. Go 编译统一剪辑计划，FFmpeg 执行成片，保存到工作区，播放、下载并继续修订。

生成模型决定镜头的具体内容和质量；工作台让输入、结果和编辑决定形成连续过程。画布媒体工具存在独立执行路径，不能把所有工具都归为时间线编译。

## 网页展示与扩展研究

网页保留咖啡品牌、产品展示、阅读倡议三个原创场景和五步互动。15 秒播放是分镜与字幕示意，不是生成视频；下载内容是 Markdown 制作说明，不是 BeefTV 可导入项目。三种架构入口展示手动、内置 Pi 与外部 MCP/CLI 的职责。

新增入口出口、八类模块职责、生成/助手/剪辑三条链路、五类场景的输入动作与预期交付、六类价值和六个建议扩展方向。每个扩展分别说明已有基础、需要补充的实现和可验证的验收目标。正文与总索引均保留完整摘要，主要结论链接固定上游提交。

## 本地运行与发布

在本子项目 web/ 运行：

    npm.cmd run dev
    npm.cmd run check

预览：http://127.0.0.1:4176/ 。发布文件位于 web/public/，所有资源使用相对路径，无运行时依赖。

在总库根目录运行：

    npm.cmd run index:sync
    npm.cmd run check
    npm.cmd run pages:build

远端工作流 Publish GitHub Pages 汇总全部已提交项目并部署。网页不请求模型、不收集密钥、不执行上游视频渲染。校验脚本检查 JS、资源/锚点和原图哈希；浏览器检查覆盖交互、下载、响应式与公开子路径。
