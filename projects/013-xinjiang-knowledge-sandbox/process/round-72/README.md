## 本轮产品变化

- 大洲采用不同的低饱和文字色、较大字号及英文辅助标注。洲与海洋先占据标注空间，国家次之；拉近后宏观名称收拢，城市与自然地理细节继续出现。当前选择始终优先，国家名称、边界、分区开关和更多标注保留。
- 新疆单独使用暖金轮廓与透明填充，不再因定位新疆而同时高亮整个中国。标签避开新疆范围本身，国家边界作为周边参照继续保留。选择其他国家时，改为高亮所选国家，新疆成为次级方位参照。
- 地球与区域地图复用同一个已有DataV简化定位轮廓。区域填充、轮廓采样贴合实际绘制的地表；在历史图层中继续显示，进入近景后收起。完整地球与原有周边继续存在，未抽出地形切块。
- 地理比较时不再描述尚未显示的路线，图例区分新疆范围、山地盆地和历史联系。聚焦天山时，喀什、吐鲁番等地点保留清晰度，只有非当前自然地理标记适度降强调。
- 地球山河标记带入对应地图对象：点昆仑山观察昆仑山，点盆地观察该盆地，沿球面进入山水格局。历史路径的四步入口继续进入所选历史联系，手动自然地理观察不再落到一个通用默认对象。
