## 实际观察

原片一号冰川岩面纹理较细，整块模型占屏较小；视频底部标注 Esri World Imagery、AWS Terrain Tiles (SRTM)、5.5×5.5 km 与约 1.1 倍显示高度。这里只记录视频中的标注，未据此核验原资产或数据精度。本地采用已署名的 10 m Sentinel-2 与公开 DEM，覆盖较大周边，显示高度 1.6 倍，近景仍受采样限制。

本地雅丹能连续展示削蚀和残丘分离，侧壁、法线与阴影同步；原片只显示初始地表和沟槽。当前对比可评价初始材质与本地动画连续性，无法证明动画全程与原作者一致。天池对应部分也只比较湖泊/山体的表现方式，不把喀纳斯区域当作天池测量对象。

## 素材与失败记录

- source/original-direct.mp4：公开原帖的完整 125.13 秒、1280×720 MP4；约 20.92 MiB，源 URL 与公共媒体信息保存在 original-direct.info.json。原许可证未确认，原视频与对比片仅本地署名研究使用，不放入 Web 发布目录。
- 首次浏览器 downloadMedia 未成功；随后公共 HLS 获取速度较慢，停止后改用同一原帖提供的 HTTP MP4 版本。HLS 元数据及未完成碎片保留在 source/，未完成碎片不视为完整视频，也不纳入源码交付快照。
- recordings/tianchi-camera.webm：1280×720 实际录屏完整母片，包含整段镜头与录制结束前的停留；tianchi-camera.mp4 为前 36 秒的 30 fps 工作副本。没有以工作副本覆盖母片。
- recordings/three-scene-switch.webm 与 MP4：天池→冰川→雅丹实际内部转场，镜头与混合收敛后切换下一景。
- 第一组录屏受到活动参考标签页的视口目标影响，实际为 883×871；H.264 yuv420 编码因奇数尺寸失败。原 WebM 和零字节失败输出另存在 narrow-attempt/，未用作最终横向对比。关闭参考页、重新设置并读回 1280×720 后录制成功。
- 首版成片 83 秒的抽查发现，天池左侧结束定格截到了原视频片尾介绍；雅丹右侧从第 6 秒开始，略过了平坦地表。首版成片、版式、脚本、检查帧与清单保存在 revision-a 命名文件/目录。最终版把原片收至 118.6 秒、雅丹从源录屏第 0 秒开始展示 36 秒，并扩大冰川裁切范围保留山体；最终成片约 89 秒。
- 冰川和雅丹使用 [R5 原有母片和工作副本](../round-05/recordings/capture-log.json)，不重复录制或伪造原始帧。
- frames/ 保存原片精确帧、约时刻联系表与成片检查帧；layout/ 保存版式、定格与裁切标记、FFmpeg 滤镜图；build-comparison.py 保存精确剪辑程序，输出章节片与主片都保留。

## 恢复与播放

重建需要 Python 3.12、Pillow、Microsoft YaHei 字体和已安装 FFmpeg 6.1.3。脚本中的工具路径按当前 Windows 环境固定，源文件哈希与时间窗见 edit-manifest.json。脚本使用 -n 拒绝覆盖已有剪辑产物；新修订应先另存旧产物，再更换输出目录。

本地播放器仅服务 output/index.html、主片 MP4 和 poster.png，不对外服务原视频母片：

```powershell
node projects/013-xinjiang-knowledge-sandbox/process/round-06/preview.mjs
```

访问 http://127.0.0.1:4314/，可以直接播放或选择四个章节。当前材料与源码在 [R6 不可覆盖快照](../checkpoints/2026-10-10-video-comparison/materials.json) 归档；R5 的交付快照不改写。
