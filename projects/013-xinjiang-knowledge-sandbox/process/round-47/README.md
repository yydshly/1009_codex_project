# R47 · 地球入口从定位变为可操作的整体认识

用户指出地球上展示太少、与目标差距大。本轮集中处理地球入口，保留既有区域地图、历史与生活场景，不继续添加局部场景或重制影片。

## 实现

六种主题改变球面表达：大陆与方位、周边关系、山地与盆地、经纬定位、距离与联系、整体到局部。大陆与海洋、中国、新疆、现代城市和邻国有球面锚点与可点标签；标签随地球遮挡隐藏，避免在背面透视显示。当前观察对象和镜头相接，原定位圈在认识入口中收起，区域填色减弱以保留底图。

三条概括山系线与两个盆地标记可继续进入区域高程地图；乌鲁木齐的纬线与经线用不同颜色相交；五个现代城市的球面距离比较同时改变高亮弧线、读数和镜头，动态可暂停。球面几何和标签对象只建一次，切换主题复用。

地球全景、欧亚大陆和靠近新疆提供不同观察尺度。进入区域地图前先靠近新疆，过程可取消或拖动接管；跨尺度淡化期间收起旧标记，避免球面标签叠在区域地图上。顶部地球入口和不含learn参数的旧planet链接接到新版，原全部探索、历史事件、地点模型仍可使用。

## 实际材料与验证

`01-earth-before.png`是用户原地球页的实际画面；它的浏览器可见尺寸为827×871。后续桌面截图为1280×720，不能当作同尺寸像素差异比较。

`02`、`03`为大陆和邻国的候选版本。`04`为早期球面三山两盆；随后减弱区域填色、收起原定位圈以保留地表纹理。`05`是城市距离比较，`06`是经纬图层，`07`记录取消并留在地球。`08`记录靠近新疆，`09`记录进入地图起始状态，`10`是全域地图抵达，`11`接回秦汉历史与事件/地点入口。`12`保留国家标签避让调整前的候选，最终地球入口用`13-world-product-final.png`；它与网页、根索引预览共享同一份内容。

`checks/distance-pause.json`记录暂停后比较线相位不变。`world-map-arrival.json`记录已到地图、球面标签隐藏且历史入口仍在；`world-topic-cache.json`记录六主题遍历两轮后GPU几何70、纹理5保持稳定，只证明这条缓存路径。`legacy-planet-entry.json`记录旧链接已进入新版、六主题存在且中国标签可见。经纬、尺度与历史DOM记录和控制台记录一并保存。

`14-overview-final.png`与`checks/overview-loaded.json`记录新增地球汇总入口；主图和距离图均加载，链接对应新版图层，桌面无水平溢出。三张网页图片与证据硬链接共享，全球底图仍使用原来的同一份文件。

浏览器旧预览连接中途失效，随后以同一浏览器的新连接完成地图、历史、重复切换和入口核验；原因未确认，未归因于应用代码。历史按钮第一次使用完整文字定位失败，依据实际data-kg-period节点操作后切换成功；失败未当作产品通过证据。

Web检查含原7项地理/内容测试与新增3项球面几何/距离测试，保留初次与最终结果。首次失败是城市距离测试的人工预期范围写错：乌鲁木齐到北京的此球面估算约2410 km，修正合理校验范围后通过；没有修改计算结果以适配错误预期。其他既有历史、探索记忆、模型、声音与字幕完整性继续通过。

根索引检查曾报告过期，重新同步后通过，分别保留`root-final.txt`与`root-resynced.txt`；不把第一次结果当作通过。

## 来源与表示范围

地理认识复核新疆政府网页的2022年概况与自然地理条目。NASA Blue Marble底图沿用本库4096×2048影像，观测年月为2004-06，没有下载新影像副本。来源与采用范围保存在`web/public/assets/world-knowledge-source.json`。

国家点不是国界、首都或边境接点；城市和大陆是现代近似方位参照。新疆轮廓沿用既有DataV定位数据，正式政区图另有官方入口。山系线只是球面位置教学，没有增加全球地形高程。距离取半径6371.0088 km的球面模型，不表示交通线路、出行里程、贸易数据或历史行程。本轮没有补充新旁白；既有影片、音频、影像和字幕保留原内容。
