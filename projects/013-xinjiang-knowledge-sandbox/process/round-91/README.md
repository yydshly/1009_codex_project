# R91 阶段归档与后续设计反思

按用户决定，将 R90 作为阶段探索原型保留。本轮整理地图尺度、真实故事细节、人物行动与后续设计，增加网页归档摘要及设计说明；不增加场景、导演幕次、人物动作、历史事实或新音视频。

## 归档范围

四主题52幕、15个工作台场景、自由操作、自动导演、暂停与接管、讲解字幕、返回地图和观察记录继续保留。R90 是运行能力基线；R91 是文档和归档入口版本。当前内容仍为选取案例和解释模型，区域、县域或历史聚落、地点细图属于后续目标。

阶段总结列出内容覆盖和缺口、产品目标偏移、宏观地图负担、故事过程不足、局部精修的顺序问题与历史表示范围。后续设计包括六尺度地图、真实事件节点表、三条历史与冰川及其他线索的扩展、开发顺序和验收条件。

## 保留方式

原轮次只读。新文档、网页摘要、检查与最终源码通过 process_store.py 在 round-90 上按 SHA-256 增量保存；旧影像、录音和影片复用原对象。Git 阶段提交收录当前源码、运行素材、总结与逐轮清单，完整历史过程材料留在本机共享库。忽略规则不删除任何材料。

源码快照在 source-recorded/，根文档和归档元数据在 source-extra/。检查结果见 validation.json，网页实际截图及阅读检查见 browser-review.json；本轮不以文档检查替代历史导演全片或历史内容验收。

## 继续开发

先读 web/public/assets/records/stage-retrospective.md 和 stage-archive.json，再整理史料与关键区域样板；编辑实时 web/，使用新轮次保存增量。保留现有其他线索和自由操作，后续导演演示同一套可控制对象。归档提交和本机素材保存不代表在线发布。
