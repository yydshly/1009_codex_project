# R20 · 恢复从地球到地点的空间主线

用户纠偏：此前生活场景串联变成“为了介绍而介绍”，丢失从地球出发、引导、从整体到局部的方向。这轮不在旧片前面添加地球片头，而是重新安排进入、定位、跨地点与返回的结构。

1. 地球：NASA 真实影像球体，旋转定位新疆，可选引导旅行或先展开区域地图。
2. 区域：用同一经纬度顶点将球面影像窗口展开成新疆 DEM，读三山两盆，锁定天山冰谷。
3. 地点：区域图靠近定位点，再进入 Sentinel-2 局部地形或原创生活情境。
4. 跨地点：集市、东北启程、伊犁抵达、哈密传习、乌鲁木齐协作与霍尔果斯分别定位；不同年代、社区和地理位置不再作为同一条街道连续飞越。
5. 返回：各地点放回新疆整体，再回到地球；结果关系图由用户打开，不覆盖最后的全球空间。

六章33段，内容时间512秒（8:32），地图进入镜头保持内容时钟，实际影片另计镜头定位与结尾停留。人物动作、五处选择、物件交接、口型与空间标记沿用R19能力，故事骨架改为空间旅行。

**声音决定**：本机未检测到MiniMax凭据。用户明确选择“先完成画面，旁白稍后补”。12条新增或改写导览只有已保存脚本，不播放内容不匹配的旧录音。21条匹配旧旁白与19条可用人物MiniMax语音保留；这不是完整新旁白的有声定稿。生成工单保存在`audio-work-orders.json`，不含凭据。

**保留材料**：`before/`是修改前源码及原生入口截图；R19完整母片、源码、历次截图和归档未覆盖。`after/`保留实际网页截图；`source-recorded/`冻结录像对应源码；`timeline.json`保存所有空间节点、时序、选择定义与待补语音；`recordings/`保存本轮实际WebGL录像与字幕/标记/选择日志。历史原片素材继续位于既有过程目录。

坐标定位案例，不是社区边界、街道测绘或建筑实景。球面展开是显示变换，定位轮廓为示意；雅丹和生活场景为原理/创作模型。不同地点的案例不声称共享同一条实测水系。源视频对应开源仓库仍未确认。
