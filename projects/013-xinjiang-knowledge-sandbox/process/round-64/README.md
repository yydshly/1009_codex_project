# R64 · 自动导演：从远行到安顿

在现有实时 3D 平台上新增「自动导演」入口，首条路线为锡伯西迁。用户点击开始后，九幕按地球定位、出发、抵达、河谷、安置、地点、先安顿、先引水、回到地图推进。直接操作已有地图与模型，不以视频代替交互。

## 编排与控制

- 历史三幕沿用已有 MiniMax 录音和字幕时间块，以音频时钟驱动历史进程、地图焦点和镜头；没有生成新语音。
- 空间桥接和家庭比较使用简短画面说明。各幕保留地域、历史问题及下一层引导；窄屏收拢信息，画布占完整空间。
- 地图镜头抵达后开始观察。家庭幕通过真实的 familyProgress、homeOutcome、waterOutcome、settlementReply 完成信号判定，而不是等待固定秒数后就声称完成。
- 自动演示只记录自己的示范结果，未写入用户的迁移观察。两种安排均明确标为导演示范。
- 暂停、继续、选幕、前后跳转、静音、重看、接管、返回地图都可用。拖动/缩放即退出导演；离开页面自动暂停，回来不强制续播。刷新带导演参数的页面只打开入口。
- 原来三条历史路径、地理对照、场景入口、自由镜头、人物选择继续保留。

## 实际验证

浏览器实际从第1幕自动运行至第9幕并显示「整段演示结束」，两项家庭回应均完成，见 browser-full-run.json / browser-checks.json。验证河谷暂停前后保持6.18秒；跳回家庭仍可继续；点击接管以及画布拖动均停止导演与旁白；退出返回连续联系地图。「我的探索」仍为原4项，未因导演示范增加。

390×844移动布局无页面横向溢出，画布780px高；1280×800桌面构图、普通窗口与原地图恢复均检查。控制台没有返回错误。网页检查66项通过；仓库检查结果另存。未把测试通过描述为画面达到原演示的质量。

## 当前边界

自动导演先覆盖锡伯路径，张骞与都护继续手动探索。史实和模型复用既有来源：1764出发、1765抵伊犁、1766春安置及后续建设分开理解；起讫方向线不是考证行程，家庭为原创情境。空间桥接与家庭幕尚无新增旁白，不假称全程都有新配音。近景材质和角色仍为已有模型，本轮重点是连续编排与可控演示。

## 增量存储

以 round-63 为基底，通过 process_store.py save 对 web 源码、截图和验证记录按SHA-256保存。相同影像、音视频、依赖与源文件复用共享对象；未输出累计打包文件。成品截图在过程库、网页和项目预览间共享硬链接。
