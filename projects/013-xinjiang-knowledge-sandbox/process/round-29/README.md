# R29 · 从位置走进选择，再把回应带到下一处

基于R28收拢同屏信息、延长地域到生活场景的连续交接，借实际完成的上一处观察改变下一处镜头与人物关注。地点、年代和社区保持独立，不把用户选择描述为历史事件或政策的原因。

本轮只新增截图、影片、验证与改动源码，基线截图共享原文件；最终用process_store.py基于round-28增量保存。原始母片采用可逐字节恢复的视频包增量，网页和Pages共享同一成片。

## 本轮画面与衔接

地图定位时读地图，抵达后短暂显示本段问题，选择时显示具体需求与可操作选项；实际交接让出画面给双手，说话时只保留对应人物对白。完整讲解、地点年代与五处观察仍可在“讲解与记录”中展开，不删去原讲稿。讲解标记只在观察和动作阶段出现，避免与选择卡和对白叠加。

区域到地点的镜头从6.2秒延长为7.4秒，增加局部展开与地域地图的交接时间。区域网格逐渐淡出，同一定位环从区域位置接到当前局部场景；新疆区域内的生活情境保留周围高程，展台底座与外框隐去。东北启程情境仍是独立教学布景，不套用新疆高程。水路与工程模型之间的两个既有转换补齐位置引导。没有提高影像分辨率或添加测量高程。

上一处观察完成后，下一处进入时才读取影响：家门来水 → 集市先关注家人；田间来水 → 先关注旅人；织物 → 家庭照护；补给／器物 → 家庭水路；家书 → 庭院先看老师；工具 → 先看学习者；观察 → 关口先看居民；参与 → 先看工作者。镜头与目光在选择前表达关注，实际交接仍等待本幕选择。不同年代、社区与地点保持独立。

## 验证与限制

纯逻辑检查涵盖信息出现阶段、已完成观察的跨幕影响和不写入新结果；19次镜头转换检查抵达端点、居中目标与起止速度；24种角色接触姿态检查共享接触点。实际浏览器选择“田间先接水”，等待回应，再进入集市，读取到旅人焦点与真实未完成的新选择，截图与数据保留在after中。

实际全片不跳段、不拖进度；原始录制、声音事件和镜头阶段另存时间清单。影片静帧能核对信息、地形展开与人物位置；不能单凭静帧验收动作自然度。人物仍是原创微缩模型，振幅口型不是音素口型，文化场景不是民族志或真实演出复原。整片混音与声音首尾采用客观核验，未以数据测量代替主观听感验收。

录制后修正了讲解面板关闭按钮被透明工具栏挡住的问题：工具栏空白区不拦截点击，面板下移。通过实际UI重新播放、展开和关闭，确认仍暂停且没有误启录制。该CSS调整不进入电影合成，录制中面板始终闭合；recording-source保留录制时的CSS规则版本，source-recorded为最终交付网页源码。镜头、人物、声音、电影合成逻辑录制后未修改。
