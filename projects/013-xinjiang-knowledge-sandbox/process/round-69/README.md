日期：2026-10-13。基底：round-68。之前轮次保持只读；本轮编辑当前 web/。

## 本轮改动

- 四个可操作目的地明确各自问题、动作顺序与回地图后的理解：喀什集市、吐鲁番水路、轮台结构、察布查尔家庭。画面底部增加当前地点入口，用户主动进入。
- 修复张骞线选择吐鲁番后，地图讲解、历史终点按钮与路径末端仍指向喀什的问题。吐鲁番延伸使用已有坎儿井模型，自动导演的喀什主线保持不变。
- 地图直接进入轮台或察布查尔时，接入完整的结构或家庭观察控制。进入地点介绍仍保留联系图层与原位模型预览，确认后再靠近并进入模型。
- 地图返回镜头按历史路径分别保存；观察按事件和地点保存，切换路径不覆盖。完成观察的地点在地图标为“已观察”，并显示实际响应及地理关联解释。
- 吐鲁番的水路记录也可带回地图；不把集市旧记录误挂在吐鲁番。
