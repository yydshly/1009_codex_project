# R76 · 张骞路径样板与完整导演配音

本轮将张骞路径连为：地球定位 → 山地与盆地 → 边缘绿洲 → 外交任务、后续往来和长期交流 → 喀什集市 → 实际人物使用与回应 → 回看喀什的地域联系。

- 导演把画布、右侧认识栏和底部字幕/播放栏分开，避免控件覆盖人物和模型。幕次折叠，背景与下一步按需展开；手机改为上方说明、中央画面、下方字幕。
- 已有真实地形与影像上增加山系、盆地观察区、蓝色流域参照和绿色地点圈。它们是观察强调，不是测绘范围、真实绿洲覆盖或历史行程。
- 同一定位图贯穿地理、历史、地点、操作与回看。张骞近景抬高机位，保留人物全身与交接空间；动态提示按真实交接和使用状态变化。织物、补给、器物的观察需人物实际完成动作才点亮。
- 回图继续保留喀什位置、联系和模型预览，并标记实际看过的用途；自由模式收拢重复说明，保留选货物、全景、暂停和返回。导演示范记录与自主观察分开，均不跨刷新保存。
- 新增14条MiniMax近景/回看普通话旁白，三条导演的41个幕次全部有音频，使用35个独立录音：26个导演音频和9个引用的旧历史音频。旧12条导演录音按请求与哈希复用，历史9条仍引用原文件。字幕按音频段落时间再切句，非逐字强制对齐。
- 新音频及旧导演音频共26条，通过解码、SHA-256、字幕完整性和混音检查：目标-18 LUFS，实测跨度0.54 LU，无失败项。最终验证见audio-device/verification.json；audio/保留首轮候选，audio-device/保留4条适配桌面与手机措辞的增量修订、请求及报告，不含凭据。原有21份录音哈希未变化，见audio-reuse-verification.json。
