# R44 · 把地点入口重新接回实时场景

2026-10-12。针对“画面呆、没有原场景丰富感”，本轮补齐地图、地点与已有实时场景之间的入口和操作。开发继续编辑 live `web/`，旧冻结素材未改动。

## 交付

- 地图保留三种地理主题，增加七地点的场景预览与可点击标记。标记碰撞时隐藏次要标签，不移动地理位置；全部地点始终可通过预览栏或地点选择器进入。
- 地点页先呈现观察问题、已有场景画面和直接进入按钮，再展开历史和资料。吐鲁番可切换绿洲生活与地下水路；其他地点接回集市、家庭、庭院、关口、冰谷和雅丹。
- 每处地理入口增加区域DEM比较线、剖面和联动游标。可以暂停、拖动取样位置；线只表示地理比较，不表示实测河道、供水路径或历史行程。
- 原有场景参数与选择控件直接挂入地点页。水路可以开关剖面、调整来水；生活场景可以选择先后、货物、安顿、参与和服务协作，并观察人物及当前动作回应。
- 教学模型接回周边区域地形背景，人物选择后的近景按可用画面宽度取景。自由旋转、缩放、相机视角、动作暂停、返回地点地图与全域地图仍可用。
- 总览新增本轮入口和实际截图。原地球、八段历史索引、三个操作事件、14场景、旧影片、字幕与声音均保留，没有重新制作整片或生成声音。

## 数据与表达范围

公开高程和影像沿用原来源；历史资料沿用R43来源索引，没有新增历史事实或外部素材。场景预览复用已有实际网页截图，人物和建筑仍是原有原创教学模型。近景周边地形是区域背景，比例与街景不表示实地测绘或某个年代的历史复原。

本轮解决可见入口、场景环境与操作衔接；人物写实度、细节密度、局部高程分辨率和全球连续LOD没有因本轮改动而升级。默认地图仍是定位示意，完整标准地图访问入口保留。

## 增量保存

执行 `tools/process_store.py save --round round-44 --base round-43 --source web --mount source-recorded`。截图、候选、文档、浏览器记录和源码按SHA-256进入共享素材库；相同预览和旧影像、视频、音频只保存一份。新预览通过硬链接展示，没有复制旧媒体，没有累计ZIP。`retention.json`记录本轮新增对象、字节和源码变化；冻结后继续开发仍编辑 live `web/`。
