# R59 · 地图与模型的接地、材质和人物动作

本轮直接改进可操作的三维网页。沿用已有 MiniMax 故事讲解、字幕和三条历史路径，不生成新的累计影片。

人物、建筑和沿线队列按显示中的地形三角面重新定位，避免真实高程网格与显示网格分辨率不同造成悬浮或穿地。移除微缩场景的硬边底板，改成沿地表铺展的柔边地面与接触阴影。地图边界降低到地表，近看时由建筑正常遮挡。较长的田垄、通道和水渠细分后投影到地形，并更新法线；静止表面复用结果。

土墙、布棚、木件、石面和水面增加共享的程序纹理、粗糙度和轻微凹凸。纹理按需建立、引用释放，不增加远程贴图请求；程序纹理是表现材质，不作为考古实物证据。

人物增加肘、膝、手足、俯身、转头与点头。集市分成走近、递接、查看、搬到摊位、放下和返回；机构空间加入过门、递接文书与回应；聚落加入照看、接收用品、带回住处与田边劳作。持有物在贴地后重新绑定到手的位置。画面线索显示当前实际动作，暂停与回拨还原同一帧。首版验收发现棚顶遮挡交接、薄面内部穿地，候选截图及修复记录一并保留。

历史讲解的章节边界与地图阶段使用同一套范围。锡伯西迁的开场先保留起讫两端的全景，再靠近河谷。这里按讲解段落对应画面，不宣称已做逐字级口型或动作同步。
