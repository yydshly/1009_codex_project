# R65 · 三条历史路径自动导演

## 本轮变化

入口提供张骞出使、西域都护、锡伯西迁三条选择。复用实时3D平台和九段既有MiniMax历史讲解；按各段音频时钟驱动地图、路线、焦点与事件变化。空间桥接和近景示范使用必要文字，未生成新语音或影片。

- 张骞：地球、出使背景、通道、周边地理、长期交流、喀什、织物、补给、器物、返回地图。
- 都护：地球、天山南侧、已有地方、机构设立、联系展开、轮台地域、入口、展开内部、双向联系、返回地图。
- 西迁：保留地球、出发、抵达、河谷、安置、地点、先安顿、先引水、返回地图。

模型幕依实际交接使用、屋盖位移与内外往来完成信号推进；跳幕不伪造结果。切换路径取消旧语音异步任务和旧动画。演示结束留在当前路径地图，可选幕或自由接管。

暂停/继续、上一幕/下一幕、直接选幕、静音、重看、切换路径、画布拖动接管、退出返回地图均保留。刷新只展示入口。桥接和模型没有新增全程配音；结构为抽象示意，集市与家庭为原创情境，不作为古城或行程复原。

## 验证记录

实际浏览器完整运行三条路线至「整段演示结束」：张骞三项货物回应、都护屋盖/通道和完整双向联系、西迁两种家庭安排均实际完成。首次整段验证结果保存在 browser-checks.json。随后针对过渡修正进行定点回归，见 mapTransitionPause/Resume、finalGeography 字段和截图14、17。

结构内外联系暂停前后均为进度0.0139、时间0.17秒，暂停不会自行续播。继续后完成返回。集市接管后可主动选择器物，原来的交接与使用继续完成。三条导演的「我的探索」均保持原4项；导演示范未增加用户探索项。结构示范带有归属标记，接管后不会把导演完成信号自动写成用户观察。

跳幕检查发现地球进入地图的到达回调曾被第二次镜头定位取消，已取消重复定位，并要求目标视图真正抵达后才能开始当前幕。暂停途中继续可重新完成到达；都护地理预导览先显示地理，再在历史幕展示机构变化。

390×844入口可选择三条路径且没有页面横向溢出，窄屏集市可暂停和接管；1280×800检查入口、地图和模型。浏览器错误日志为空。网页70项检查通过，仓库19项目检查通过。单元检查新增路径与讲解绑定、切换路径取消过期加载、三路径完整时序、人物/结构完成门槛。未把通过检查表述成美术质量达到原视频。
