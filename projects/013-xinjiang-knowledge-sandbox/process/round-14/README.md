## 进入画面的具体机制

| 场景 | 需求与选择 | 变化与人物回应 |
| --- | --- | --- |
| 家庭与聚落 | 先引水/先安顿；选择带来的家书或工具 | 家人打开行装，物品交到孩子手中，孩子回应；成年人讲述记忆或参与日常技能学习 |
| 传习庭院 | 选择十二、刀郎、吐鲁番、哈密木卡姆资料；参与一拍 | 资料卡与学习关注改变；示范者留出停顿、学习者接续，同伴整理记录 |
| 当代关口 | 听附近居民、货运工作人员、生境维护者的三个需求 | 三位角色站立围桌表达；镜头推近协商桌，把生活边界、交接与维护放到一起 |
| 空间安排 | 集中转运、轮换通行、保留生境 | 方案、人物、车位、缓冲带和车辆等待共同变化，每种选择保留仍需协调的需求 |
| 结尾回看 | 选择自己的观察记录 | 返回家庭物品、文化资料与关口安排，恢复本页选择 |

完整融合线为山地冰雪与来水 → 绿洲生产 → 集市交换 → 历史调遣与家庭生活 → 另一社区的文化传习 → 当代公共服务与空间协商 → 回看选择。自然、地理、历史、文化、民族、经济、政治通过环境、人物与组织方式进入故事；民族目前是两个社区案例，政治是历史调遣与当代服务治理两个切面，未覆盖所有民族、全部制度或完整社会经济体系。

## 事实与创作边界

- 国家民委资料支持 1764 年调遣、1765 年抵达伊犁、1766 年迁居察布查尔及之后修渠开垦；语言文字与西迁纪念资料支持后来的文化记忆主题。
- UNESCO 资料支持四类木卡姆区域风格与社区传习。资料卡是内容导航，选中卡不表示正在表演该风格真实曲目。
- 国务院 2023 年方案支持片区分工、服务协同、土地使用与生态保护要求。三方角色、协商桌与三种场地安排是教学创作，不是官方程序或实施成效。
- 家庭、孩子、服饰、建筑、家书、工具、人物动作、教学拍点和对白为原创。未使用伪造锡伯语或档案复刻，未复制真实木卡姆音乐、舞步或真人录音，不模仿民族口音。
- 西迁家庭与木卡姆庭院属于不同社区；真实山谷属于不同集水区。舞台线路连接主题，不表示真实距离、同一家人的连续经历或单一水系。

来源链接、日期、对应段落与采用范围完整保留在 [sources/research.md](sources/research.md)。
