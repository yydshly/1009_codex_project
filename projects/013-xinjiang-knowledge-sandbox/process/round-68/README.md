# R68 · 地球、地图、历史与地点接成一条线

日期：2026-10-13。基底：round-67。以前轮次只读，继续编辑当前web/。

## 实现

1. 三路径共用地图讲解状态：地势 → 联系 → 地点模型。画面高亮、路线展开、模型预览、文字说明使用同一进度；第三步沿球面靠近地点并采用倾斜视角。
2. 点选、播放、暂停与拖动接管；地图步骤写入链接，刷新恢复但不强制播放。
3. 从当前地图进入历史，复用已有语音与字幕，不强制回到地球再走一遍。
4. 进入历史前保存地图镜头、方向、节点和图层；返回恢复。模型中已经完成的观察带回对应地图，导演与自主记录仍分开。
5. 三条导演都在地球之后增加共享的新疆地图幕；西域都护原重复的地理幕合并。原有模型操作与历史音频保留。
