# R99 · 演示首页与总结等页面互相关联

用户要求演示首页关联总结、各页都能相互到达。发现R98虽已添加总结链接，但kg-active及小屏历史导航会隐藏nav内文字链接。将总结与总览入口移到工作台品牌旁，独立于可滚动工具导航；旧demo增加受保护的总结与总览链接，研究及手记也增加总结入口。总结页明确提供3D首页、项目总览、原视频和指南；指南补明确总览链接。

通过浏览器实走：3D首页→总结→开发指南→总览→总结→3D首页。另在500px视口验证当前首页两个项目入口可见并点击总结，检查旧demo默认入口保留总结与总览。测试后恢复原视口，未操作旧演示播放或原用户页面。导演与自由探索共用工作台页头，入口移出隐藏规则的作用范围。
