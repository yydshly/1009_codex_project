# R46 · 四幕生活场景与地点探索

用户目标：丰富集市、家庭、庭院和关口的人物动作与环境，让地图进入场景有视觉落点；继续保留自由操作、选择后的变化与地图返回。交付是实时3D网页，四幕可以独立进入，也保留地球、全域地图、历史索引和事件操作。

## 本轮实现

- 集市：下垂布棚、木构货台、磨损铺地、储货、编篮、手推车和驮包绑带。商队在交接后沿前侧留出空间，避免进入摊位；选择织物后孩子披裹，补给和工艺沿用原交接与用途。披裹改成弧形织物表面。
- 家庭：门窗与门槛、晾晒、器皿、行囊、田边叶片、渠岸与步道；家庭分散停留，避免所有人重叠。选择后用2.4秒缓步接近门前，滑杆接管可以取消这一段；家书/工具交接、引水/安顿先后继续可操作。劳作工具加入双手接触。
- 庭院：分枝、薄叶与果串替代重复的椭圆叶；共享实例减少重复几何；铺地、器皿、边缘坐凳与学习桌构成日常空间。点击参与一拍时，桌边学习者同步回应，示范者留出停顿并致意。去掉学习者整个人随节拍缩放的效果。
- 关口：等候遮棚、行人边缘、单据和交接工具、植被缓冲。方案继续改变绿带与车队，角色姿态和表情对应响应；暂停时缓冲变化也停止。
- 地点进入沿用地图定位→靠近经纬度→生活场景的衔接，并为四幕加入明确近景落点。原手动接管、取消与地图镜头恢复继续使用。
- 四幕有简短操作引导与实时过程标记；单一模型进入后隐藏重复入口按钮。总览新增四张实际网页截图和直接操作入口，地点预览更新为当前画面。

## 实际画面和操作核验

`01-market-before.png`为本轮修改前集市。`02-family-before.png`含进入期间的地形淡化叠层，属于过程素材，不作为最终画面。`03`、`05`为候选近景，`04`为早期家庭选择状态。四幕之前的完整源码和画面继续保存在round-45，未复制。

`06`与`07`记录关口轮换/保留生境方案的实际变化；`08`为返回地图，`09`为靠近地点，`10`为近景抵达。`11`记录集市选织物后的搬运，`12`为孩子披裹后的最终画面。`13`记录家庭从约84%缓步接近，`14`为工具交到孩子手中的最终画面。`15`为参与一拍后的庭院近景，`16`记录暂停状态下自由转动；`17`为取消进入后留在地图。

`18`为四幕总览。`19`保留调整取景前的最后候选；集市入口为避免裁掉左侧摊位，最终使用`20-market-entry-final.png`的宽落点，选择后再靠近对应接收者。`12`仍是选择后的实际近景，用于网页与根索引预览。

核验记录在`checks/`：

- `market-choice.json`：织物选择、交接完成及使用状态。
- `family-choice.json`：进程从0.843到1.000；工具、接收者、渠水和安顿结果对应。
- `courtyard-response.json`：参与计数、桌边回应动作与实际接触状态。
- `gate-pause.json`：暂停前后车队、植物缓冲及脚步相位保持一致。
- `free-camera-paused.json`：暂停时镜头改变，脚步相位不变。
- `map-return.json`：返回后相机位置、目标点与进入前读数完全一致。
- `reentry-cache.json`：同一庭院场景重复进入前后，GPU几何116、纹理7，未增加；仅是这一缓存路径的检查，不代表整站内存验收。
- `overview-dom.txt`与`18-overview-final.png`：四幕入口与实际截图均加载，桌面总览无水平溢出；`browser-console.json`记录产品与总览此连接的警告/错误。

Web地理/内容完整性、人物24组接触和动作音集成检查使用现有检查，记录保留初次与最终结果。浏览器核验以本轮实际连接为范围，不宣称完成多浏览器、写实人物或全局性能验收。其他最终预览、缓存计数及控制台记录在相应检查文件中。

## 数据、声音与表示范围

依赖仍为项目现有Three.js，真实高程与影像沿用原来源；新增铺地细微起伏只在原创教学地面上使用，未改实测DEM。建筑、器物、服装与练习动作不是特定年代、民族服饰或真实木卡姆演出的复原。四幕仍是风格化人物，地球到模型仍有尺度切换，没有引入全球连续LOD或近景扫描。

原影片、33条导览、19条人物语音、声音与字幕文件保留同一份内容；本轮没有复制媒体、生成新语音或导出新影片。直接体验实时3D页，可暂停、自由转动、切换地点、选择参数与返回地图。

## 增量去重

执行 `tools/process_store.py save --round round-46 --base round-45 --source web --mount source-recorded`，截图、候选、验证、文档与源码以SHA-256共享保存。网页四张预览、根索引预览与本轮截图通过硬链接使用同一份内容，旧影片与音频未增加副本。对象、增量字节和源文件变化见`retention.json`；冻结后继续开发编辑live `web/`，既有冻结素材只读。
