# R27 · 把一个生活问题带完整，再把回应带回地图

2026-10-11。基于 R26 实帧审阅，重新组织水路、集市、历史家庭、文化庭院与当代关口之间的承接。贯穿的问题是“人怎样在这片土地上生活，并与外界建立联系？”。各案例仍有独立的地点、年代与社区，不虚构共同水系、同一家人或跨时期的历史因果。

## 主线的实际改变

- 先看坎儿井怎样输水，再决定家门与田地的用水顺序。供水完成后直接追问物品与补给，返回山前节点与喀什，去掉主线中的雅丹侵蚀岔路；雅丹和湖泊仍可独立探索。
- 集市的接收者留下货物，商旅继续走，引出“需要长期留下的人怎样安顿”。先在新疆定位伊犁，再明确转入 1764—1765 锡伯西迁，随后回到区域定位哈密，比较不同社区中下一代怎样参与。
- 关口读取集市、家庭与庭院的观察。庭院的倾听／参与会改变带入的问题说明，不替用户决定公共空间方案。
- 关口选择之后继续留在同一处，镜头标记已发生的回应和仍未满足的需要。轮换通行、集中货运与保留生境各有独立的约束；后续镜头保留原选择。
- 回望展示五处实际观察的三维物件与“下一步仍需回应”，再返回新疆和地球。未访问的案例不伪造已完成结果。
- 贯穿问题同时出现在交互网页与影片中。新增可分享的 `?demo=1&cue=...` 地点入口，打开时停在该场景，不替用户自动选择。

十九条导览重新生成 MiniMax 普通话语音，与新主线一致。原有三十三条导览总量、十九条人物分支语音、环境层与接触音系统保留。声音及动作是原创教学表达，不是现场录音、史料引语或真实木卡姆曲式。

## 验证与素材保存

`story-continuity.test.mjs` 验证水路顺序、历史案例进入方式、庭院到关口的记录承接、三种公共安排留下不同未尽需要，以及未访问案例不冒充结果。浏览器分支审阅、整段实际录制与声音首尾核验另存本轮文件，以实际结果为准。

本轮以 R26 为基线按 SHA-256 增量保存，不生成历史累计包。旧版影片、R26 对比截图与源码记录继续只读保留。凭据只从外部 `.env.minimax` 读取，不写入任何请求参数记录或素材清单。

## 实际交付结果

完整影片 10:28（628.484秒），1280×720、H.264/AAC、8章节。完整自然播放保留33段主线与全部演示回应，视频轨未重新编码。按本轮原录制波形测得并校正 80ms 声音提前量；41段实际声音的首秒和最后可闻秒核验通过，最大时序偏差 5.5ms。集成响度 -18.0LUFS，真峰值 -2.3dBFS。

浏览器货运分支验证后续镜头保留集中转运、绿地22%教学参数，标记“居民缓冲与连续绿带仍待回应”。`after/story-comparison.jpg`对照R26截图与R27实际帧，时刻分别标明；不是伪造同步镜头。
