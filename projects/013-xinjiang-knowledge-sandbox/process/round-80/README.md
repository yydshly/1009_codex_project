# R80 · 第一次出使的地图远行与荒漠使团

把张骞远行从宏观叙述推进到可操作画面：地域方向、十余年中断、荒漠行走、迎风护脸减速与停留取水；接入自动导演的两幕，再回到外交结果、长期交流与喀什的生活机制。保留自由镜头、暂停、回拨、接管及返回历史地图。

地图采用长安、陇西方向、大宛与大月氏的现代地域参照，不是考证逐站行程。扣留地点不定点。五位人物、驮马、沙丘、旌节、行装与动作均为原创，未作具体地貌或汉代服饰的考古复原，也不表示张骞真实随从人数。唐代敦煌壁画不作为汉代服装复原依据。

新增两条MiniMax speech-2.8-hd普通话旁白，交付时长25.596秒与27.828秒；保留原始MP3、交付MP3和不含凭据的生成摘要。第二条合成成功后字幕文件下载失败，使用已保留音频与文字时序降级，没有重发合成。交付响度目标−18LUFS、真峰值−1.5dBTP。37份独立录音服务43幕导演；旧音频与影片不重存。环境声为原创WebAudio合成。

实际浏览器检查：远行路线与荒漠两幕自然推进，再接回历史；两幕都有实际播放音频与画面字幕。暂停状态选幕及滚轮操作保持暂停，自由接管成为可操作近景。手动风沙开关、50%迎风段、70%补给段、路线点选、进度回拨和返回历史地图通过。390×844窄屏调整了介绍面板与标记避让；恢复正常窗口。未将这些局部检查写成三条全片重新验收，新增合成接触音未单独录音测量。

发现并修正使团被前景沙丘遮挡的问题：加宽通道，避免行进附近出现大石块，跟随镜头按视线自动避开沙丘；降低默认观察角度以保留荒漠地平线。自动检查覆盖101个位置、三种动作阶段及两种画面比例的视线间隙。
