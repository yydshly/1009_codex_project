# R78 · 导演下方直接选幕，观看时可调整镜头

本轮针对用户反馈：选幕直接摆在下方，缩放或转动不应暂停自动导演。保留此前三条历史路径、旁白、字幕、模型操作及返回地图。

## 完成的行为

- 下方常驻幕次条，当前幕高亮；小屏可横向滚动。切幕和窗口大小变化后，当前幕自动进入可见范围。
- 滚轮缩放、拖动转动只取得当前幕的镜头控制；演示、旁白、字幕、地图变化和人物动作继续。
- 主动暂停后再缩放、拖动或恢复镜头，仍保持暂停，不自动恢复。
- “恢复导演镜头”回到当前幕构图，下一幕恢复新幕构图。明确选择自由探索或返回地图才退出导演。
- 进入地图、地点或模型的镜头飞行尚未结束时，手动调整先完成当前空间到达，再调整视角；保留进入模型的回调，防止丢失地点状态或卡在等待。浏览器切到后台仍沿用原暂停规则。
- 字幕、控件和幕次条在画布外预留空间。桌面底栏174像素，小屏216像素。

## 实际验证

1. 地球滚轮缩放：相机位置改变，导演与音频继续；历史阶段拖动同样继续。
2. 主动暂停后的拖动、缩放、恢复构图：时间保持7.07秒，音频仍暂停；恢复演示后可继续自由调整。
3. 在暂停时直接选幕：切换到所选幕，继续保持暂停。新幕重置为导演视角。
4. 地图镜头飞行中缩放：保留逻辑到达，没有卡在等待；喀什近景缩放时旁白与人物交接继续。后续自然推进到补给幕，织物实际使用回应仍被记录。
5. 390×844小屏：页面宽度390，画布底628，底栏上628；无横向页面溢出，当前幕完整可见。缩放、拖动没有解除主动暂停。
6. 西域都护14幕、锡伯西迁13幕入口和缩放实测：导演和音频继续；明确返回地图停止导演。控制台错误为空。
7. 主检查98项通过，包含3项新回归：镜头调整不停止旁白或跳过人物回应；暂停后操作不恢复演示；新幕恢复自动构图。

本轮是导演交互修正，不是三条完整演示重新验收。R77保留西域都护、西迁两条完整顺序播放核验；R76的全部配音与素材继续复用，未重新生成旁白或影片。
