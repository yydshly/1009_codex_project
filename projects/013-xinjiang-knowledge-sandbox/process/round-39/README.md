# R39 · 地球、主题、事件、地点与模型连成可操作路径

本轮继续面向可控制3D平台：从全球方位进入新疆整体地图，以地理与水主题认识空间，再选择重大历史事件，观察背景、过程与影响，放大地点、操作模型并返回。保留原14个场景、自由镜头、参数、过程时钟、配置与探索记录。

## 实现与实际画面

- 地球先定位新疆，再进入区域。进入期间提供定位状态；手动操作镜头可以中止引导。图鉴从地球选点时，等区域到达再靠近所选地点。
- 地理、水与历史主题逐级承接。历史地图直接选择张骞出使、西域都护或锡伯西迁，地图节点与路线同步更换；初次展开事件从背景开始，不受旧的100%进度影响。
- 事件采用统一探索条：背景 → 过程 → 影响 → 地点 → 模型。过程仍可拖动、运行、暂停、单步或倒退。路线、商队与交换网络、机构建筑、迁徙方向、聚落与水渠使用已有真实对象联动，不只改介绍文字。
- 地点与模型内保留新疆定位小地图及事件节点。模型中改选节点，同时切换地点与适用模型；人物选择后的实际回应出现在引导区。手动模型选择可退出事件联动继续自由操作。
- 返回新疆时恢复原主题、地图视角、选点和镜头。配置导出包含有边界的regionContext，页面导入恢复模型后仍可返回原地图位置；旧导航配置兼容。
- 原模型工具按需打开，结构展开与部件选择仍可达。减少重复地点标记，事件地图保留区域轮廓；中等窗口扩大地图取景，给引导区留出画面空间。
- 塔里木与伊犁关系说明独立，流域名称不再误触发吐鲁番选点；这些仍为概括流向，不把不同地点串成同一水系。

## 实际验证

826×870浏览器中实际点击、选择、导出和导入，记录见[browser-verification.json](browser-verification.json)，断言见[validation.json](validation.json)：

1. 张骞事件0%、50%、100%依次改变路线与网络；西域都护改变建筑与联系；锡伯西迁改变远行、聚落和水渠。
2. 喀什 → 集市 → 选择织物后的家庭需要回应；模型定位小地图改选吐鲁番，实际切换到坎儿井。
3. 都护 → 轮台 → 结构模型，展开屋盖并选择内部空间；切换到西迁事件，再进入察布查尔家庭，返回显示新的事件地图。
4. 水主题 → 吐鲁番 → 模型 → 返回，主题、选点和镜头保留；[真实页面导出配置](water-turpan-model-config.json)导入后恢复相同模型镜头，再返回相同水主题与选点。
5. 地球图鉴 → 冰川选点 → 冰川模型 → 返回同一选点。中止地球入场后自由镜头保留。
6. 原3份已保存配置及4条探索记录数量不变。[三事件切换3轮](event-resource-cycles.json)，各事件GPU几何与纹理数量稳定；只代表本轮切换操作，不是全部模型内存基准。

曾发现直达区域链接误触发延迟地球入场，导致选点丢失；候选记录保留，修正后重测直达链接、导出导入与返回均通过。第一次完整地球入场超过单次浏览器等待上限，随后实际页面正常到达；没有把等待超时当作已完成动作。

根索引同步、根检查、Web检查结果记录在checks.json。新增导航状态的边界清洗、兼容恢复与事件路线节点通过Web检查覆盖。实际截图不宣称验证移动端。

## 数据与表达边界

沿用[R38轮廓、影像与地形来源](../round-38/README.md)及既有历史资料，没有新增高程、影像、语音或影片。地球为NASA影像球体，区域与局部使用原有高程网格。尺度切换使用先定位、靠近和画面过渡，尚非全球连续地形分级加载。

事件节点为现代地域参照，概括路线不表示逐站史实行程；张骞线为盆地南缘教学廊道，锡伯区域线仅联系伊犁与察布查尔，全球方向不是完整西迁路线。机构、集市与家庭均为原创教学模型，未作考古建筑或真实社区复原。原产品源码仓库、引擎、版本和许可证仍未确认。
