# R66 · 地球上的国家范围与中文标记

2026-10-13。用户要求：地球地图更详细，清楚标记国家范围。

## 实际改动

- 引入 Natural Earth 1:50m 国家与地区多边形，共242个地理条目；保留岛屿、多面几何，现代范围与历史事件分层。轮廓、淡色分区和中文标记覆盖原球面影像。
- 点击球面名称或定位菜单，镜头与选中范围同步变化。中国高亮时仍保留新疆定位，周边关系与地形主题优先显示新疆八个邻国；全世界其他条目也可定位。
- 名称按缩放、球面遮挡和布局碰撞分级显示；小屏最多10个国家名称，桌面最多30个，背面标记隐藏。边界、名称、着色独立开关，链接/刷新保留选择。
- 清楚显示图例、当前位置与资料依据。地图及历史近景仍沿用原有交互，国家图层不冒充古代疆域。
- 一份合并边界几何、一张复用2K着色纹理；选中范围变化时释放旧高亮几何，不叠加网格或纹理。

## 数据依据

[Natural Earth 国家数据5.1.1](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/)；[陆地边界5.1.0](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-boundary-lines-2/)；[公共领域许可](https://www.naturalearthdata.com/about/terms-of-use/)。从官方维护仓库获取GeoJSON，原件在 source/ 压缩保存。完整SHA-256、版本、地址和显示名称调整见源码内 assets/world-countries-source.json。

保留来源默认实际控制范围表示，来源中的争议/未定段叠加虚线。不是测绘级或官方标准地图。经拓扑保留简化0.025度并保留3位小数，几何约776 KB；现有NASA影像未重复下载。中国、台湾、美国、英国、朝鲜、韩国使用常用显示名，俄罗斯标签移到亚洲部分；这些调整不修改原始几何。
