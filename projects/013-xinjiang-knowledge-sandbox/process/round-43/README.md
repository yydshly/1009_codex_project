# R43 · 地球、地图、历史与地点的认识入口

本轮补齐可控制3D平台的基础认识层：先建立全球方位与尺度，分层阅读新疆全域定位，再按八段历史索引找到问题和地域，进入相关地点与原有模型。用户可以直接改选时代或地点、自由操作、返回地图，不依赖视频时间轴。

## 本轮交付

- 默认首页及 `?learn=world`：位置、经纬度、整体与局部三个基础主题，邻近区域、定位新疆与区域入口。
- `?learn=map`：地形骨架、水与绿洲、城市与区域三层。完整显示轮廓小图固定北向，14个主要现代城市参照可定位，俯视与侧视可切换。官方标准地图提供发布与获取入口。
- `?learn=history`：史前、秦汉、魏晋南北朝、隋唐、五代宋辽金元、明代、清代、近现代八段。各段呈现背景、变化、影响、观察问题、资料依据与地点延伸；3D地点与教学关系线随选择变化。
- 秦汉索引接入张骞、西域都护两个原事件；清代接入锡伯西迁事件。操作完可通过“认识新疆”回到本次时代索引。
- `?learn=place`：吐鲁番、喀什、察布查尔、哈密、霍尔果斯、一号冰川、雅丹原理七个问题入口。每处说明为什么来、观察什么、模型与史实的关系，并提供相关时代线索。
- 地点地图进入原有模型，保留自由相机和“探索”操作面板。返回恢复本次地点地图镜头。旧山河与通道、14个场景、3个事件、影片、字幕、语音和观察记录保留。
- 总览主入口与说明同步更新为R43。旧影片仍是历史演示，没有当作本轮实时平台录像。

## 资料与表达范围

来源索引见 `sources/provenance.json`。政府概况、文旅考古资料、中国社会科学网、国家民委和UNESCO用于核对主要位置、年代与专题线索，检索日2026-10-12。地图轮廓、DEM、NASA影像沿用既有来源，未下载新的地理栅格、模型、音频或视频。

地图的全域轮廓是定位示意，不是官方政区边界或历史辖境。现有DEM仍覆盖 `[73,35,96,49]`，部分轮廓超出裁片，超出部分不推算高程；完整轮廓小图与官方标准地图链接负责补充位置认识。14城市列表不是全县级或兵团城市全集。官方标准地图图像未嵌入：原发布站点图片下载出现TLS连接失败，保留官方发布与获取链接。

八段历史是阅读索引，不是完整地方史。现代地域参照、教学联系线、历史记载和原创情境分开说明。模型延伸不意味着对应时代已经存在该模型中的器物或场景：小河与雅丹是环境比较，隋唐与吐鲁番用水是异地机制比较，明代与当代文化传习是跨时期延伸。没有把原创建筑或人物称为遗址、真实家庭或历史复原。

## 实际验证与素材

操作状态与URL记录在 `browser-verification.json`。`screenshots/` 保留初始画面、候选、修正后和最终截图；未覆盖旧轮次。重点截图：`27-world-final.png` 地球、`28-history-han-final.png` 历史、`32-map-full-outline-final.png` 地图、`18-family-model.png` 人物、`22-karez-model.png` 结构、`26-karez-mobile-settled.png` 移动宽度模型。

验证了八段时代各自改变地域点、三种地图主题、14城市列表中的和田定位、历史到三个原事件及返回索引、清代到家庭模型及参数选择、地点历史延伸、地下水路进入、模型返回地图、默认首页与原山河通道入口。900×800和390×844用于窄屏检查，模型标题遮挡经过修正，临时视口复位。控制台warn/error读取未发现记录。

`web/scripts/check.mjs`通过：原场景/声音/资料完整性、事件阶段与进度、地图返回上下文、真实DEM剖面和新增内容链接检查。内容测试检查来源/地点/事件/模型引用是否有效，不替代历史资料人工审核。根索引和Pages汇总检查另见 `checks/`。

没有重播完整旧影片或重新做声音验收。本轮主要交付是实时平台的信息结构与操作入口，尚未增加新的遗址测绘模型或全球连续LOD。所有时代还没有各自独立的动态历史复原；只有原三个事件具有现成的背景、过程与影响操作。后续应先扩充可核对的地方史与实物证据，再决定哪些值得做成新的3D观察机制。
