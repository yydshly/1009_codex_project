本轮依据用户指出的故事线差距，重构入口、讲解与结果。用“远离海洋，怎样成为连接之地？”贯穿六章、30 段、7 分钟内容；九个物理场景与 38 个自由探索镜头继续保留。

## 故事与交互

| 章节 | 承接的问题 | 跨领域关系 |
| --- | --- | --- |
| 山水 | 来水在哪里 | 自然、地理 → 生活条件 |
| 绿洲 | 人怎样利用条件 | 水、工程、维护 → 生活与生产 |
| 道路 | 道路上交换什么 | 地理、历史、经济 → 知识与文化 |
| 人群与记忆 | 谁移动、为何移动、如何延续 | 历史调遣、家庭与伊犁；木卡姆的社区实践 |
| 当代 | 通道如何被组织 | 三片区功能、产业分工、政务与生态要求 |
| 共生 | 条件变化牵动什么 | 水源、利用、保护与制度 → 七节点关系图 |

结尾可以选择水、通道或迁移的跨领域问题，查看相应解释与出处，返回讲解或接管场景。文化与现代片区在真实区域地形上定位，城市中心与联系弧线为教学标记，不代表法定片区、文化分布或实际交通路线。自然条件、历史经历与制度共同参与解释；案例不概括所有民族与社区。
