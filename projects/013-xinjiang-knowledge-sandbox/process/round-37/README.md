# R37 · 可操作的3D探索路径与观察回溯

2026-10-12。本轮围绕最终产品的使用路径开发：地球定位新疆，地图选择自然地点或历史线索，观察空间变化，进入地点模型，自由参与，记录结果并返回。保留原14个场景和旧影片；新增的交付是3D网页中的操作能力。

[进入3D平台](http://127.0.0.1:4313/1009_codex_project/013-xinjiang-knowledge-sandbox/) · [网页汇总](http://127.0.0.1:4313/1009_codex_project/013-xinjiang-knowledge-sandbox/overview.html#exploration-loop)

## 使用路径

1. 转动地球观察新疆的内陆位置，点击“定位新疆”或“进入新疆整体地图”。
2. 在地图切换自然地理、历史入口或“一起看”。绿色地点定位自然模型，金色地点进入事件；地图标记与投影位置以引线对应。山地与盆地整体观察仍可选择。
3. 选择张骞出使、西域都护设立或锡伯西迁线索。“下一步”只运行到下一观察阶段后停下；路线、队伍、结构或安置过程同步变化。也可暂停、单步、调速、倒退或直接选择地点。
4. 在地点进入模型。集市选择物品、家庭选择记忆与生活需要、结构展开屋盖与选择部件；自由操作会接管事件联动。人物的实际状态会显示在当前观察中，便于对应画面。
5. 点击“记录当前观察”，暂停并保存当前镜头、参数、事件进度和人物回应。通过“我的探索”恢复原状态，或返回地图继续选择。顶部路径也能直接返回上一空间尺度。

三条事件各自记住观察进度和地图视角。记录保留最多12条，同一观察更新保存；只保存小型配置，不复制遥感影像、音频、模型或影片。浏览器不允许本机保存时，会提示导出配置。导航配置升级至版本3，兼容版本1和2。

## 相关场景与来路

| 当前观察 | 可继续比较 | 保留的返回状态 |
| --- | --- | --- |
| 冰川 | 地下水路结构 | 自然地点、地形参数与镜头 |
| 地下水路 | 绿洲用水 | 原模型、来源上下文与操作状态 |
| 集市 | 绿洲用水、当代关口协作 | 历史事件、地点、物品选择、交接结果与镜头 |
| 家庭 | 庭院传习 | 历史事件、家庭选择、人物回应与镜头 |

这些是观察问题与机制的比较。不同地点、时代与社区各自独立，不表示实测相连水系、同一家庭的后续生活或历史人物的连续行程。“返回原观察”在当前操作过程中可用；需要跨刷新保留相关场景的来路，应记录观察或导出配置，普通场景URL不包含完整返回配置。

## 实现与修正

- `history-platform.js`：地图中枢、可点击空间路径、按阶段停止的引导、各事件记忆、人物反馈、观察记录和相关场景返回。
- `exploration-memory.js`：导航与配置验证、12条记录上限、去重、单层返回上下文、新旧配置兼容。拒绝不相配的模型与地点配置，避免恢复后画面和说明矛盾。
- `history-map-layer.js`：自然／历史入口、已记录标记、标签避让与地点引线。切换时释放旧地图入口与事件资源。
- `lived-scenes.js`：恢复集市交接序号、已交付物品和次数，避免恢复选择时重复累计交接。
- `sandbox.js`：记录时暂停原模型模拟；整体地图以新的探索入口为主。
- 网页总览、研究、设计说明、README、项目索引同步当前可操作能力。旧参考视频、影片、声音和历史探索保持可查。

## 实际验收

真实浏览器操作见 [browser-verification.json](browser-verification.json)。[resource-cycles.json](resource-cycles.json) 保存六次连续事件切换的资源计数；同一事件在两轮切换中的几何、纹理与事件网格计数一致。本项只检查该操作链，不是整个浏览器堆内存的完整测量。

- 新版本配置导入恢复结构展开、通道选择、镜头和三条既有观察；旧R36配置也恢复，未清空当前探索记录。
- 事件切换恢复各自不同的50%／100%进度；引导运行后停在50%，URL与控制状态一致。
- 家庭选择工具后，交接到孩子手中并出现回应。进入庭院比较后返回，恢复原镜头、工具选择、结果和暂停状态；再记录没有增加条目。
- 从探索记录恢复集市的织物选择、原镜头与交接结果，交接次数保持1；刷新后仍可恢复。
- 合并地图的六个入口标签在实际桌面视口中没有互相遮叠，[投影与矩形记录](map-pin-layout.json)可查。没有进行移动端浏览器验收。
- 地球、地图、模型与观察回溯路径，以及网页总览均通过实际操作检查。新纯状态测试覆盖匹配关系、去重、数量限制、旧配置和有界返回上下文；根索引检查及子项目检查结果见 [checks.json](checks.json)。

[初次实际导出的配置](exported-exploration-config.json)保留三条观察；[最终实际导出的配置](exported-final-config.json)保留四条观察，包含人物选择结果。两者都是网页下载结果，不是手写模拟数据。[验收断言](browser-assertions.json)基于保存的实际读取。

浏览器诊断字段可能留有先前场景的隐藏状态。验收以当前 `platformStage`、`workspaceScene`、事件进度及当前模型相关字段为准，不把隐藏旧字段当作画面中正在发生的内容。

## 当前边界

地球与区域之间仍采用定位、相机靠近与画面过渡，没有实现连续的全球地形分级加载。区域与地点复用既有真实高程和固定日期影像；本轮没有提高数据分辨率。模型和人物仍是简化原创表达，史实路线、考古建筑复原和经过标定的模拟仍需独立资料与资产。原视频对应的上游仓库、内部引擎与许可尚未确认。

历史资料继续使用已有来源与区分：丝路跨时期交流参照UNESCO资料；西域都护与乌垒背景参照新疆文旅考古综述；锡伯西迁、安置和后来修渠分别参照国家民委、新疆档案馆与大渠资料。现代地点用于地域参照，动画不构成逐站行程或政策成效证据。页面按需显示来源与具体边界。
