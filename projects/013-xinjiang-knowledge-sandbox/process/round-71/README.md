## 下一轮建议优先级

- 首先统一洲/国家/地区/城市/自然地理/当前讲解对象的标注规则。颜色需与字号、字重、背景和缩放显示规则共同使用，不仅靠颜色辨识。洲名可有不同低饱和强调色，但当前讲解对象应独占更醒目的强调样式。
- 同步强化新疆范围：清楚的连续轮廓、轻透明填充、周边适度降强调。讲山系、盆地、河谷和历史事件时，保留新疆整体方位；靠近地点后保留一个可返回全域的参照。
- 讲解与当前状态一致：提到的对象高亮、名称和引线对应、路线按段变化；当前只看地理时不描述路线已经出现。只在切换重点时适度提示，避免持续闪烁。
- 简化入口与控制：一个主要下一步，次要能力保留但收起；明确当前空间尺度、主题、事件、时间与所选地点。
- 统一图例语义：范围线、自然地理强调、地域联系、起讫方向与历史示意不能看成同一类线。选中天山后，关键关联地点仍应能读清。
