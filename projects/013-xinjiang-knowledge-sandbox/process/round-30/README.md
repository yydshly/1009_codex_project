# R30 · 重新复核整片，并补齐必要介绍与字幕

本轮重新连续播放原片与R29整段成片，按入口、尺度、用水、集市、家庭与庭院、关口、回望复核差距。最该优化的是同一地理目标与人物需要的接续、选择后果和时空门槛。没有宣称场景与人物已经重新制作完成；本轮交付阅读支撑和具体的画面优化顺序。

[逐段复核与证据](audit/README.md)保存本轮网页截图、原片8帧和R29新抽取24帧，包含健康度、具体时刻、优势、问题、下一轮验收与证据限制。历史R23/R28/R29画面留档不替代本轮证据。

## 本轮交付

- 网页播放器新增默认导览字幕层、开关和保留字幕的播放器全屏。原生字幕在当前内嵌浏览器未稳定显示，因此使用可见DOM层，WebVTT仍保留下载与其他播放器使用。
- 33段导览按实际MiniMax音频文本生成句段字幕；8段所选人物回应已有画面内字幕，默认不叠加同一句。完整字幕文件与文稿包含41段实际语音、73个句段。
- 播放器下分幕显示地点、年代/案例性质、上一幕问题与本幕关注。完整文稿可按时间跳转，同时更新介绍并保持暂停；不强制开始播放。
- 交互版增加导览字幕开关，开启声音时跟随语音时钟，静音时跟随导览时钟；既有人物对白继续显示。后续新录制的画面也包含开启状态下的导览字幕。
- 当前网页差距区更新为本轮复核、六个分段判断和下一轮最先完成的空间—需要—选择—后果链。

## 影片与过程素材

影片仍为R29完整10:42原文件，SHA-256 `776ed30fa6eb6abf866cdfbd5a846c087577f13a1fe72b58cfdba9d4f045a2b7`。本轮没有复制、重录或重编码完整影片。R30“字幕阅读版”是可开关字幕、介绍与文稿的新层，画面、混音和已有原声保持R29文件。原片也复用原归档。

R30基于R29按SHA-256增量保存，新增截图、新抽帧、字幕、脚本和变化的源码保持独立轮次清单。没有累计ZIP。影片通过网页、Pages和过程素材共享原文件；不是再保存一份R30大视频。R30自身的轮次和素材索引在冻结后派生更新，不递归纳入自身源码快照。

## 验证与限制

字幕覆盖与片段首尾边界、文稿内容对应、暂停/跳转/字幕开关/全屏显示已经核对，另保留实际UI截图与数据记录。语音片段起点来自R29已验证波形，内部句段时刻按源音频停顿与字数估计，未完成逐句人工听校或逐字强制对齐。截图与抽帧不证明运动自然或主观声线质量。

本轮不新增历史、社区服饰或公共决策真实性结论；原片与当前影片不是同地点同比例测试。下一轮先在冰谷、吐鲁番用水和集市完成一个可静音读懂的链条，再处理家庭—庭院—关口的时空切换与不同人物的结果动作。
