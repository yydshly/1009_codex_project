# R88 · 统一入口与探索主线

## 本轮目标与变化

保留已探索的能力，整理地球→新疆全域地图→历史事件→地点模型→返回地图的主线，不增加场景、声音文件或人物小动作。

- 地球入口保留大陆、国家与新疆范围。主界面只显示三个尺度选择与进入全域地图；经纬、距离、水汽、交流、国家图层与专题仍能展开使用。
- 四级导航贯穿自由探索。重复的左侧标题、路径步骤、浮动讲解卡、定位/进入的重复确认收拢；历史播放器承担背景、过程、影响、字幕和进入下一层。
- 从地球进入新疆先停在完整区域，保持周边地理；主动选择地形、历史关系或地点后再靠近。历史关系的三条入口各自同步地理对象、事件与地点模型。
- 张骞、都护、西迁的事件影响幕可一次进入关联模型，镜头先交代地点位置再展开模型。单独的定位、分析和旧工具折叠保留。模型的实际变化、人物回应与返回地图继续沿用原有能力。
- 年代索引、相关历史入口和“下一历史阶段”共用切换规则，清除上一事件的路径状态，避免史前/隋唐/近现代误带张骞或西迁的控制。自由历史入口也使用统一播放器。
- 研究总览收拢为认识新疆、历史路径、自动导演、原视频、研究记录与资料来源。原专题、对比、蓝图与过程内容移入可展开的研究记录；原锚点可以自动展开对应内容。

## 实际浏览器检查

1. 地球入口→完整新疆区域，空闲后仍停留全域，没有自动跳到喀什或局部模型。
2. 张骞：区域关系→历史三幕→影响→一次进入喀什集市→织物进入家庭→人物实际使用和回应→返回交流地图，观察记录仍可见。
3. 都护：区域关系→历史→影响→轮台地域→抽象结构，入口、屋盖与通道往来演示仍能运行；可返回机构与地方地图。
4. 西迁：区域关系→历史→影响→察布查尔模型，1766年春起的住处、水源与耕作可以播放；可返回伊犁地图。
5. 三条自动导演从入口实际完整播放到自然结束，张骞15幕、都护14幕、西迁14幕。分别呈现3项集市用途、2项结构观察、3个水利年代结果；三个测试页无控制台错误。测试播放关闭扬声器输出，沿用真实音频时长与字幕，没有替换成缩短时间或静态截图。
6. 导演选幕、暂停后缩放、继续播放、播放中缩放、自由接管与返回地图实际检查。滚轮调整镜头不停止播放；主动暂停保持暂停。自动示范观察与用户本人操作记录分开。

## 范围与保留

本轮没有提高人物/建筑的写实程度，没有增加历史考证内容，没有重新制作视频或音频。三条历史路线的背景与结果不等同：张骞经历与长期交流分别表达，集市是跨时期机制情境；现代轮台是地域参照，抽象结构不是乌垒实测城址；锡伯安置与后期修渠按年代区分。地球到地点仍使用定位、镜头与已有局部模型衔接，尚非全球连续高精度地形引擎。
