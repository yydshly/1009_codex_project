# R35 · 地球、整体地图与历史事件的可操作3D平台

2026-10-12。用户明确保留既有能力，将入口顺序调整为：全球认知、整体地理、重大历史事件、具体地点与模型。交付是实际网页的导航与操作，不以新影片作为产品。

## 使用入口

[进入当前3D平台](http://127.0.0.1:4313/1009_codex_project/013-xinjiang-knowledge-sandbox/) · [项目总览](http://127.0.0.1:4313/1009_codex_project/013-xinjiang-knowledge-sandbox/overview.html#blueprint)

1. 地球默认显示欧亚大陆与新疆定位。可旋转、缩放，点“定位新疆”或球上的定位标记，再进入新疆整体地图。
2. 整体地理地图显示山地与盆地。可选自然观察入口，也可直接切换历史事件。
3. 三条事件均有年代、问题、三个阶段、地域参照、资料来源和模型性质。点地图标记或右侧地点按钮靠近，再选模型。
4. 在模型中自由观察、调整参数与模拟。返回事件地图恢复进入前的视角，能选择另一个地点或事件；地球入口始终可用。
5. “全部场景与原有工具”保留14个原场景。配置保存、导出与导入增加导航背景、结构展开与选择部件，不复制素材。

## 实际实现

- `history-content.js`：三条事件、六个地域节点、四个自然入口，各自资料与模型分类。
- `history-platform.js`：地球/区域/事件/地点/模型导航、返回视角、URL状态与配置恢复。
- `history-map-layer.js`：随真实区域高程定位的可点击标记、教学廊道、阶段反馈与抽象空间结构。结构可展开屋盖并点部件解释，选中部件同步高亮。
- `sandbox.js`：复用原有模型与参数，平滑定位、进入靠近与画面过渡；自由拖动可接管镜头。保存现有场景的相机、参数与模拟状态供返回恢复。
- 总览页提供直接3D入口、实际画面和事件入口；R34蓝图折叠为历史提案，原片与R31旧影片继续按需加载。

## 内容依据与边界

| 事件 | 资料依据 | 地点与模型怎样使用 |
| --- | --- | --- |
| 公元前2世纪 · 张骞出使西域 | [UNESCO长安—天山廊道](https://whc.unesco.org/en/list/1442/) | 敦煌、喀什为现代地域参照；盆地南缘廊道不是张骞逐站行程。吐鲁番作为绿洲生活的延伸观察，坎儿井没有指定历史年代。 |
| 公元前60年 · 西域都护设立 | [新疆文旅厅2022年考古综述](https://wlt.xinjiang.gov.cn/wlt/mtbd/202303/2c41806b10f84069bbbe1adb542db056.shtml) | 轮台地区是定位参照，不是乌垒遗址坐标。城门、道路、围墙与内部空间是抽象结构，不能由模型推出史实布局。 |
| 1764—1766 · 锡伯西迁与安置 | [国家民委锡伯族历史沿革](https://www.neac.gov.cn/seac/ztzl/201806/1067551.shtml) | 全球迁移方向、伊宁与察布查尔地区参照；人物与家庭原创。地下水路只作工程类比，不声称复原察布查尔水渠。 |

继续使用既有NASA影像、公开DEM、Sentinel局部影像与原创教学资产。原产品仓库、引擎与许可仍未确认，本轮没有取得或引入原产品源码。

当前尺度切换使用定位、靠近与画面过渡；没有全球连续地形LOD。局部影像仍为原始10米产品，人物仍为简化原创模型。三条事件是本轮已接通的内容，R34其余专题不视为全部实现。

## 增量保留
