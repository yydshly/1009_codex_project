# R31 · 冰谷、吐鲁番用水与集市的需要和动作接续

本轮重录并交付完整10:46影片，六章33段的内容时钟8:44。主要改造前半段：地球定位后沿同一目标靠近冰谷；转到吐鲁番先看两处用水需要，再展示先接水、另一方等待、接通第二支渠、田间工作和维护；行装旁的空篮与补足的水引出物品需求，沿道路定位喀什，交换后继续照护、装包或制作。不同地点仍是问题比较，并非同一条水系或同一物品的真实运输。

## 具体画面和选择

- 区域显示定位轮廓，演示时隐藏裁片边墙与模型底座；定位环从区域坐标接到局部高程窗口。轮廓仅是定位示意，未引入行政边界测绘数据。
- 用水选择等待需要读完再自动发生。第二支渠在第一方开始工作后接上；家人给孩子接水，田边的人先等待，再沿湿润田垄工作。植株不再瞬间长大，不把教学动画当作生长预测。
- 使用、竖井维护、行装准备保留同一绿洲世界，取消两次重复区域定位。镜头依次靠近闸口、先接水的人、另一方、维护井和行装。
- 道路网络在绿洲节点和喀什靠近之前展开。集市织物成为孩子的披裹，补给放进背包并带动出发动作，器物落到工作台后继续制作；未选的两位仍保持需要。
- 全片内嵌33段导览与8段所选人物对白。网页保留7段地点/案例性质介绍、41段可按时间定位的完整文稿与下载字幕；没有再次叠加同一句导览。

## 真实记录与验证

[完整影片](recordings/xinjiang-spatial-story-r31.mp4)为实际连续WebGL录制，保留地球入口、全部章节、选择、对白与结尾；只截去结尾8秒停留之后的额外等待。视频轨道未重新编码。混音按真实波形补偿509毫秒的录制音画偏移，最终解码响度−18.8 LUFS、真峰值−5.7 dBFS。全部33导览、8人物回应的首尾波形通过，最大实际时间偏差6.375毫秒。这不代表逐字口型同步或主观声线已获验收。

[工作顺序](work-sequence-verification.json)来自录像逐帧后采样的实际状态：家庭已接水而田边尚待；随后两支渠都接上；水路使用到维护无空间飞行；行装出现物品需要；集市织物分支继续照护，另两位等待。[关键帧索引](after/frame-index.json)标明12个实际影片时刻。[前后对比](after/chain-comparison.jpg)复用R30从旧R29抽取的帧和本轮新帧，语义取点不同，不做纹理增强。

首轮与第二轮混音候选出现结尾峰值超标，未上线。第三次保守峰值余量并关闭AAC声强立体声/感知噪声替代后通过实际解码检查。所有候选的容器、音频与原始字节均保留，不复制共同的视频包。

## 源码与增量保存

`tools/`中的录制时8个画面脚本保留当时实际版本；`source-recorded/`为本轮最终网页源码。录制完成后修复了交互版“暂停续播自动重新开启声音”，关闭声音后续播仍静音，另修正用于后续录制的简短承接行参数。当前影片保留已录制的地点栏、定位镜头小地图与地形标记，没有补造新承接行的录像。两处修复不更改已录制的场景、动作或对白。

母片和两次未采用混音按 `tools/media_master_store.py` 保存差量：共同AVC包复用最终影片，原始AAC、容器和多余尾段存入 `.nonvideo.gz`，`.media.json`完整记录重建路径和SHA-256。保存前逐字节校验恢复结果，通过后才移除重复完整容器。需要查看原候选时，按[恢复指南](../../storage/README.md)执行restore；素材没有丢弃。

R31基于R30按SHA-256增量冻结，每轮截图、实帧、影片、声音时间日志、验证、未采用候选和源码记录均保留。旧R05至R30只读不覆盖，原片、旧影片、未改声音和遥感数据继续共享。网页、Pages与本轮影片只使用同一文件，未累计打包ZIP。R31自身的轮次索引在冻结后派生更新，不递归纳入自身快照。

## 保留的限制

人物仍是简化创作模型，近景地形沿用原10米影像和高程，没有新增摄影级表面或民族服饰复原。行装桌与人物的遮挡、动作接触仍可继续打磨。静帧及状态日志不单独证明动作完全自然。家庭—庭院—关口的时空门槛与不同后果仍有改进空间；本轮没有宣称整片已与原演示质量相同。
