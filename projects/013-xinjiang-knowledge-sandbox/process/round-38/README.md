# R38 · 地图与主题成为新疆入口

用户反馈：R37地图过于单一，新疆入口与参考原片差距明显。本轮针对实际可操作3D产品重做入口与地图组织，保留已有模型、事件、自由镜头与观察能力。

## 对照依据与本轮实现

对照[原片入口000秒](../round-33/frames/reference-000.jpg)及[专题024秒](../round-33/frames/reference-024.jpg)。原片通过大幅地形、轮廓、基础认识、主题卡片、地标图鉴与模型目录建立丰富入口；本轮没有重新制作演示影片。

- 地球与区域共享探索入口；从中国西北、欧亚内陆定位进入新疆全貌。大幅地形取代两侧常驻工具栏围着小沙盘的布局。
- 三条主题：自然地理、河流与绿洲、交流与聚落。四种地图视角：地形格局、水与绿洲、历史路线、地点图鉴；实际更换名称标记、关系线与入口对象。
- 三山两盆名称贴合区域位置，可点选并靠近；公开简化轮廓强调新疆、区外地形压暗，超出DEM的段落仅虚线定位。
- 11个区域内外地点参照可分类、搜索、定位与打开关联模型或历史事件。模型目录提供原有14个场景；图像复用既有实际截图，未提供场景截图的条目只使用定位图标和文字。
- 自由镜头、原工具、事件阶段控制、观察记录与旧配置保留。导航v3增加有边界的mapLayer、atlasEntry，实际导出、导入恢复地图视角、选点与镜头；原v1/v2/v3兼容。
- 主题改变时释放上一组三维几何与材质，复用DEM、区域与局部影像。没有新增电影、语音、累计ZIP或重复影像。

## 来源与表达范围

区域和局部高程、NASA与Sentinel影像均复用原有数据。R38没有增加高程或遥感分辨率；显示网格插值不等于新采样。

轮廓来源：[DataV 650000 GeoJSON](https://geo.datav.aliyun.com/areas_v3/bound/650000.json)，2026-10-12读取。原始1220点使用Douglas–Peucker简化到363点，容差0.035度；保留[原始数据](xinjiang-boundary-source.geojson)与[处理/哈希记录](boundary-provenance.json)。端点未声明数据许可证，坐标体系没有独立核验；区域定位显示不作为测绘边界，没有引入上游代码。原始SHA-256：`5082287d7b0b1a01582560f8381854960484498f9ba45a763b8b5f388c516afc`。

现有DEM范围为[73,35,96,49]，而公开轮廓延伸至南侧覆盖界限外侧等区域。轮廓超出DEM的部分置于定位平面并用虚线显示，不夹用边缘高程伪造覆盖。地球显示完整简化轮廓。

“三山两盆”与流域方位参考[新疆水利厅公开介绍](https://slt.xinjiang.gov.cn/xjslt/c114428/202309/a90332286c0c4dcaa0305131e18bb01c.shtml)。蓝线是人工概括流域关系，不是实测河道或把冰川、吐鲁番、伊犁串成同一条水系。金线为既有绿洲交流廊道示意；青线仅联系伊犁与察布查尔位置，不表示完整西迁路线。

三条历史事件沿用R36依据。人物、庭院、关口与抽象机构空间为原有教学情境；地点入口与真实社区、遗址复原分别说明。原产品代码库、内部引擎、版本与许可证仍未确认。

## 实际验证与截图

1280×720浏览器实际操作，证据见[browser-verification.json](browser-verification.json)：

1. 地球定位、区域与四种地图视角可操作；最终地形视角显示三山两盆五个名称。
2. 水与绿洲 → 吐鲁番定位 → 坎儿井关联模型 → 返回区域，保留自由操作。
3. 历史入口 → 西域都护事件：0%、50%、100%对应背景、机构显现和联系变化，继续使用真实对象联动。
4. 图鉴自然分类返回天池、冰川、雅丹；搜索“喀什”只返回喀什，并可定位。
5. 原有14个场景均进入模型目录；地图图鉴11条入口可达。
6. URL恢复水与绿洲及吐鲁番选点；[实际导出配置](water-turpan-config.json)通过页面导入恢复选点、地图视角、暂停状态和镜头；原3份保存配置、4条探索记录仍保留。
7. [四地图视角连续切换3轮](resource-cycles.json)：同一视角的GPU几何数量分别保持9/11/15/25，纹理数量保持4；该测试没有观察到按切换次数增长。仅代表本次操作测试，不是所有模型的内存基准。

[R37基线](screenshots/00-r37-baseline.png) → [新版最终入口](screenshots/11-region-final.png)；[水与绿洲](screenshots/12-water-final.png) · [地点地图](screenshots/13-all-places-final.png) · [最终图鉴](screenshots/14-place-catalog-final.png)。01—10截图保留布局候选、模型操作与过渡时刻，不作为最终静态成品。09为地球入口定位画面；早期10模型目录中的坎儿井缩略图后已更正为无截图条目，最终模型目录复用准确的场景缩略图。

## 增量保存

以round-37为基底，使用`tools/process_store.py save --round round-38 --base round-37 --source web --mount source-recorded`。保留本轮截图、候选画面、实际配置、操作记录、来源与Web源码，文档与元数据另存docs-recorded。旧影片、影像、音频与冻结记录按哈希继续复用；网页预览使用硬链接，不另存同一图片。衍生轮次索引在冻结后更新，以免快照自包含自身清单。

本轮解决入口与地图的呈现和探索组织。更多专题知识、高质量资产、近景人物表现、连续全球地形仍有差距，没有宣称达到原片全部品质。
