# R55 · 张骞出使与西域都护的完整探索路径

从地球定位新疆，经过整体地图与具体历史问题，先定位地点，再由用户主动进入集市或抽象结构，最后带实际观察回到同一事件地图。原西迁家庭路径、自由操作、地图分析、影片、声音与场景保留。

## 两条路径

- 张骞：大陆位置 → 盆地边缘地理参照 → 出使背景、往来与跨时期交流 → 喀什 → 货物交接。织物给家庭，补给给远行者，器物给手艺人；实际使用与后续动作完成才生成观察。标记随接收者位置和状态变化，暂停不提前完成。
- 西域都护：大陆位置 → 天山与盆地北缘 → 地方聚落、机构设立、地域联系 → 轮台地区 → 抽象空间结构。部件高亮、视角聚焦和屋盖位移真实作用于模型；选中部件并完成展开后，才记录结构观察。
- 地图变化沿用可逆的球面事件对象。三条路径分别保留本页的模型、镜头、事件进度和观察；互切不串记录，原家庭选择继续可用。轮台新增为第八个地点入口，结构不再需要跳进另一套事件界面。

## 表达边界

沿用既有UNESCO丝路与新疆考古资料，没有新增史实推断。张骞出使是外交活动；金线、商队和集市解释跨时期的往来与交换，不表示张骞的实际行程或某次停留。现代轮台仅为乌垒研究的地域参照；机构、联系线和结构模型不复原遗址、布局或辖区边界。人物和使用动作均为原创教学情境。

观察与精确镜头在本页打开期间保留；刷新仅通过URL恢复入口、尺度、地点、表面类型和历史进度，不恢复个人观察。未新增扫描资产、全球LOD、旁白或影片。
