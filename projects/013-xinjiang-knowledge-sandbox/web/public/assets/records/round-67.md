# R67 · 地球范围、标记层级与连续进入

日期：2026-10-13。基底：round-66。编辑范围：当前 web/，以前轮次保持只读。

## 本轮实现

- 四步地球入口：全景、周边、山河、进入新疆；定位菜单与三个国家图层开关位于首屏。
- 国家名称悬停与键盘聚焦预览轮廓，点击/Enter 才改变选择与镜头；一键回到新疆。
- 标注预算同时考虑宽高，山河视图收拢；更多标注选项写入URL。避让标题、导航、图例、导演与镜头工具。
- 山河着色减淡，进入新疆时名称与国家轮廓依次渐隐；取消或返回完整恢复。
- 国家预览使用单个可替换轮廓对象；移除约242个不用的国家圆点网格，缓存标签顺序和法向量。

## 实际浏览器检查

1. 1280×800：周边视图预算22、山河17；手机390×844和窄屏660×871预算10，无水平溢出。中国与八个邻国在周边视图可见。
2. 聚焦哈萨克斯坦时只有预览变化，当前选择仍为中国；Enter 后定位与高亮同步。打开更多标记后刷新，设置与国家选择保留。
3. 进入新疆期间捕获渐隐中间态；抵达后stage=map；返回地球再取消进入，图层恢复，透明度为1。
4. 经纬图层仍可访问；三条导演路径入口保留，张骞首幕可以播放、暂停并退出回联系地图。本轮未重放全部三条路径。
5. 浏览器错误日志为空。完整项目检查结果见 browser-checks.json 与 check-output.txt。
