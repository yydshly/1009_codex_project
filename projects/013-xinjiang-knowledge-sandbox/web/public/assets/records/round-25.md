# R25 · 让空间导览与人物的声音接上画面

2026-10-11。补齐十二条 MiniMax 空间导览，用人物的实际渲染支撑相位、道具移交状态和演奏动作触发原创材质音；分场景环境声随镜头淡入淡出，人声出现时压低背景。保存整段实际 WebGL 和混合音轨录制，统一响度后展示在项目总览。

## 声音与画面的对应

- 十二条新导览从地球定位、三山两盆、冰谷观察接到集市、西迁、庭院、当代节点与回望。使用 `speech-2.8-hd` 和既有旁白声线；九条更新旧文本，三条新增，目前共33条导览、19条可选角色对白。
- 脚步由距离驱动的脚掌支撑相位发出，静止、跳转和暂停不按计时器播放。声音随人物在镜头中的位置轻度左右定位，并随距离降低。
- 集市交接3.8秒、家庭移交55%、接水70%、庭院记录移交55%、关口提案放桌95%等读取实际动画状态，材质分别使用布、木、陶器、纸与金属的原创合成声音。
- 手鼓和拨弦读取正在演奏的角色相位；观察轮次停奏。声音与动作均为原创教学练习，没有录制或复原木卡姆真实曲目。
- 星空、山地、水路、风沙、集市、家庭、庭院和关口有不同环境层，约1.6秒淡入淡出。人声播放时环境声降低约9.4dB，庭院人声有轻微早期反射。

## 验收与保存

实际影片、语音首尾匹配、接触音日志、镜头和截图见本轮文件；最终测量值以 `recordings/media-verification.json` 为准。`speech-and-sync-verification.json` 检查实际成片的所有33条导览和演示分支对白，校对首秒、末尾可闻秒与声源事件时间。

口型仍由实际对白的音量包络驱动，未新增音素口型。分场景声音属于原创表达，不是当地声景的实地采样；本轮技术测量与画面审阅不冒充主观听感或民族音乐学验收。

MiniMax 凭据只读取本机外部 `.env.minimax`，没有进入请求记录、源码、网页或素材清单。保留不含密钥的请求参数、响应摘要、生成母音与归一化交付音。接口依据：[MiniMax 同步语音合成](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)。

R23影片、原帖原片和所有历史素材保持只读。新母片、成片与源码通过 SHA-256 增量归档；网页、Pages构建和过程入口复用同一个成片文件，不复制为额外媒体资产。R25基于R24清单保存，不生成累计ZIP。归档索引包含本轮清单的步骤在快照形成之后由同步脚本生成，避免清单自引用。

## 最终交付与实际核验

完整影片 `recordings/xinjiang-spatial-story-r25.mp4` 时长10:30（630.460秒），1280×720，H.264/AAC立体声，8个章节。保留33段主线、全部抵达和回应、结尾8秒停留；原录制末尾返回导航不进入展示片，仍可从母片还原。视频轨逐包复制，没有重新编码画面。

实际测得 −18.0 LUFS、−1.5 dBFS真峰值、13.9 LU响度范围；首轮试混18.8 LU，声音落差已减小。校正原录制两个时间基准造成的声音提前427ms。33段旁白与8段当前演示分支对白均与实际MP3波形匹配，首秒、最后可闻秒和时序通过，最大时间偏差41.6ms。19次环境层接续覆盖8类场景。声源记录有639次脚掌／演奏接触、20次道具阈值事件，另有选择反馈。

录制日志原先被脚步等动作的kind字段覆盖，造成首次漏计；当前源码已修正日志字段顺序，声音生成未改变。`source-capture/`保存实际录制的两个源码差异文件，`source-recorded/`为交付时完整源码。`foley-waveform-verification.json`在326个无对白窗口中抽查材质频段与时间，7个代表样例通过，涵盖脚步、木器、纸张、鼓、弦和关口闩锁；无法强隔离的布与纸声照实保留结果，不声称全部声音均已逐次波形确认。前两种全频／高通探查报告继续保留。

`after/`的8张实帧与联络图来自成片原始画面，未增强纹理。网页直接播放该整片，原帖视频继续按需加载。项目、声音同步、实际人物脚步、HTTP范围播放和统一Pages构建另有检查日志。
