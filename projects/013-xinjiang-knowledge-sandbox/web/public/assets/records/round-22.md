# R22 · 地点、旅程与前后幕选择

继续落实“地图成为故事空间、前幕选择接入后幕、统一信息层级”的方向。目标是改进当前独立实现的体验；没有取得原网页和源码，不声称等同原项目。

本轮实现：

1. 六处案例在持续可见的影像地图上定位。地图保留首次浏览顺序与本页实际选择，可以选点、回到新疆、恢复刚才的场景；区域入口的卡片与地标也呈现已留下的选择。
2. 绿洲的家门/田间选择改变集市首先关注的需求与自动演示分支。集市的物品用途改变历史家庭的观察重点；家书/工具交接改变庭院的观察/参与起步方式。交互模式不自动替用户选择，仍可改选其他项。
3. 六个区域内人物场景的进入使用真实三维顶点展开及生活模型的空间变换，取代这几处进入时的静态图像叠化；抵达后，区域高程和影像作为地理背景保留。其他地形、原理与返回镜头沿用原有过渡。
4. 移除大部分悬空说明牌，只保留小型商铺名称。场景讲解每次显示一个对象标记；人物发言时定位图收起，避免覆盖对白。
5. “关系图”里的旅程回顾把本页实际选择放回地点地图，并提供回到具体地点的入口；自动演示自然回到地球，回顾面板由用户打开。

范围与依据：地理背景窗复用既有区域DEM及NASA影像，经过教学显示变换，不是新增高分辨率地形或测绘街区。模型依然是原创简化布景。旅行连线是首次浏览顺序，不是历史道路或同一实测水系。锡伯西迁记忆、维吾尔木卡姆与当代关口是独立案例，前幕选择延续的是访问者的问题，不改变实际历史或真实政策。12条空间导览旁白按用户决定继续后补，原49个MiniMax文件未替换。
