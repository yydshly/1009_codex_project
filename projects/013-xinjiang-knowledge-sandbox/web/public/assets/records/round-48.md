# R48 · 让新疆地图接上地球、历史与地点

本轮继续沿产品的多尺度认识路线开发：保留R47六种地球图层，把进入新疆后的地图做成可选择、可读高程、可进入事件与场景的认识入口。

## 实现与边界

地图有地形骨架、水与绿洲、城市与区域、通道与历史四种主题。五个山地/盆地对象、三个流域/盆地对象、14个现代城市、两条地理通道观察线分别改变地图图形和标记。选中对象改变焦点、镜头、DEM取样线与剖面、相关时代和地点入口。北向箭头随地图旋转，白点与高程读数一起移动；取样扫描由用户启动和暂停。

全域地图重新取景，收起默认横向场景图鉴以让地形成为主画面；图鉴仍可打开，七个地点和原14场景继续保留。城市用微型积木作位置符号；山系与流域为概括线，选中环为观察焦点，不是地质范围、国界、实测河道或历史道路。

从选中河谷、盆地或通道进入历史索引时，保留刚才的地图镜头与地理图形，写明从哪个问题进入哪个时代，事件操作按钮提前。通过本入口打开已有张骞、都护、西迁事件后，返回全域会接回所选地图；事件模型/地点的中间返回仍走原层级。事件的既有过程动画、模型选择和用户暂停保留。

到具体地点仍先靠近，再进入模型，人物选择与回应保持原有实现。回到地点地图后，可以再回到原全域选点与镜头。地理选择也写入URL，刷新保留当前主题选点；精确自由镜头只在本次探索中恢复，不声称URL存储了全部镜头。

DEM、NASA区域/全球影像、影片、音频和近景模型全部复用。没有新增实景扫描、历史复原模型、声音或影片。全球到区域仍是镜头与画面混合，并非全球连续LOD；近景与人物的既有写实精度没有提升。本轮不表示整个平台已达到原产品的成熟程度。

## 验证

- Web检查12项全部通过，保留初次与最终日志。新增测试检查各地图对象的高程线始终在DEM范围内，链接到有效历史、来源和地点；线段加密不丢转折和端点。原事件、探索记录、影像、声音和字幕完整性继续通过。
- 地球→地图抵达后旧球面标签隐藏、地图标记与北向提示可见。
- 天山取样起点0 km约595 m，终点约778 km约868 m；暂停后位置/读数不再前进。数值来自本库既有DEM，不表示现场测量精度。
- 河谷→历史→事件→地图，以及河谷→家庭→地点地图→全域走通。`map-history-return.json`中前后镜头与目标数组相同；`event-direct-return.json`保留伊犁选点与水主题。`model-region-return.json`记录场景返回。
- 四主题遍历两次，同主题GPU几何计数分别108/114/109/111，纹理6，第二轮一致；只证明本次图层切换路径没有持续增长，不替代整体性能审计。
- 自由拖动后镜头变化，北向由0附近转到约40.8°；当前天山选点保留。地点图鉴可以打开与收起。
- 820×870与390×844检查，手机文档无横向溢出；测试结束已清除视口覆盖。控制台检查没有错误或警告。

汇总页新增记录链接后，打包检查发现R48记录尚未暴露到Web路径；建立与本轮README的共享硬链接后重新检查通过。保留了缺失链接的检查日志。

根索引首次检查发现新预览路径多写了子项目前缀，改回项目内相对路径并重新同步后通过；失败与修正结果分别保留。

第一次等待家庭进入的选择器超时；随后读取实时状态，确认已进入人物场景、镜头与过渡均settled，再保存截图并验证暂停、选择和返回。没有把该等待失败当作产品通过。`family-choice-dom.txt`保留实际控件与回应。

## 来源与增量保留

表示范围见 `web/public/assets/map-learning-sources.json`。本轮复核UNESCO长安—天山廊道与新疆水利厅河流文章：地形、城镇、用水与交流共同理解，不能把一条现代点连线当作考证行程。新疆概况本次抓取超时，沿用R47核对的2022地理条目；未加入时效性人口、经济或冰川统计。

以round-47为基底执行 `tools/process_store.py save --round round-48 --base round-47 --source web --mount source-recorded`，保留所有候选、截图、检查和源码记录。按SHA-256共享内容，网页预览与证据硬链接共享，不重复复制历史影片、音频、DEM和NASA影像。新增对象与字节以 `retention.json` 为准。冻结后不再修改本目录。
