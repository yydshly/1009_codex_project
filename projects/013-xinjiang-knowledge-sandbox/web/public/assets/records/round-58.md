# R58 · 让历史讲解在地球表面有可见的变化

本轮集中补强三条历史路径的实时画面，沿用 R57 的九段 MiniMax 旁白。用户自己播放、暂停、选择观察点或靠近；进入地点与模型仍由用户决定。

张骞路径增加驮兽、行人、包裹、布棚集市与交接动作；西域都护路径增加原有聚落、门洞、围墙、门塔和院落的分段成形；锡伯西迁路径增加家庭行装、住房、田垄、灯火与后续渠水。商旅按曲线方向和球面法向前进，局部步态、货物摆动与讲解共用可暂停的时钟。队列在集市外围停留，缩小抬高棚顶，给人物交换留出无遮挡的空地。

天山、塔里木盆地和伊犁河谷沿用已有地理坐标增加贴地强调，背景、发生、影响三幕使用不同强度。每幕提供“看全局／看变化／看局部”三个观察点，宽景交代方位，斜俯视靠近模型；另有“靠近看变化”。关闭引导或拖动地图后，讲解不会把镜头抢回。画面标记避让字幕和镜头卡，地点标签抬到模型上方，影响段减少移动符号的重复标签。

本轮修复了加载旁白期间近看仍可能开播、关跟随未取消正在进行的转场、暂停转场后继续未恢复当前镜头，以及章节末端字幕与镜头越幕的问题。暂停同时保持动作和相机；回拨仍能还原较早阶段。

## 记录与范围

screenshots 保存修改前、三条路径、近看、家庭选择和窄屏的实际画面；checks 保存浏览器观察及自动化验证。检查包含暂停、自由镜头、章节边界、曲线队列、球面朝向、地理锚点不漂移、机构可逆变化、安置和后续渠水分期，以及进入家庭、完成选择后返回原地图。

这些微缩模型是教学符号与原创情境，仍不是考证行程、管辖范围或遗址复原。沿用真实区域影像与高程，没有新增高分辨率影像；近景写实品质和全球连续 LOD 仍有局限，不把本轮视为达到原参考的全部品质。

以 round-57 为基底，用 process_store.py save 按 SHA-256 增量冻结本轮源码和截图。正式语音、旧视频与历史素材继续共享内容对象；不新增累计影片，不复制旧媒体。归档完成后更新网页素材索引，开发源文件仍保持独立可写。
