# R42 · 山河与通道，成为可操作的一条线

本轮把“地球定位—三山两盆—历史通道问题—吐鲁番—地下水路”做成独立交互主题。地图优先呈现，问题引导观察，用户随时环视、缩放、切换步骤、返回地图或展开原有历史事件。区域纹理升级为NASA原生500米裁片。保留全部原场景、原视频、声音、字幕和历史版本。

## 这轮能直接操作什么

入口`?explore=passage&exploreStep=world`，也可从原区域入口“山河如何成为通道”进入。顶部五步自由切换，不依赖固定时间轴。

1. 转动地球、定位新疆，进入整体地图。
2. 沿南北取样线看三山两盆，切换侧看与俯看，读取实际区域DEM剖面。
3. 选择直线跨盆地或沿盆地边缘，地图线、剖面、距离和沿线示踪同步变化；可暂停、重播、拖动取样位置。
4. 走近吐鲁番，观察从天山侧到盆地的高程参照，再进入模型。
5. 展开/覆盖地下剖面、调整来水、暂停水路动画；点击竖井、暗渠、出口定位结构；返回恢复通道和地图相机。

“展开张骞出使事件”进入原有事件的背景、过程、影响与地点入口。原3历史事件、14原场景、11地点入口、我的探索、原相机工具和配置功能继续保留。

## 画面与数据

- 新材质：`xinjiang-blue-marble-500m.jpg`，5520×3360，5,583,914字节；来自NASA BMNG 2004年6月含地形阴影的C1/D1原生500米块。
- 原始URL、下载字节、SHA-256、裁切框及经纬度投影记录：源码中的`public/assets/regional-imagery-500m.json`。原全球下载约161MB，仅临时处理，不长期保留；新存区域裁片一次。
- 区域DEM仍是769×513。没有用更高分辨率图片声称提升高程精度；材质不增加假地形。地区矩形边缘在展示模式淡化。
- 教学比较：直线约1594km，边缘线约1757km；距离按地理段计算，沿线高程来自区域DEM。补给、可通行性、真实历史路线不能由这些数值直接推断。
- 北南剖面约1368km；天山侧到吐鲁番剖面约141km。并非整片新疆最高点，也不表示与某条真实地下水路实测连通。
- 现代地域参照、原创线路与通用工程模型，未声称张骞逐站行程、停驻吐鲁番或坎儿井建造年代。

资料复核：NASA官方BMNG页面，UNESCO长安—天山廊道（1442）与坎儿井预备名单（5347）。引擎Three.js固定0.186.1 MIT，原版权声明保留。未取得原产品源码，也未确认其开源仓库/内部引擎。
