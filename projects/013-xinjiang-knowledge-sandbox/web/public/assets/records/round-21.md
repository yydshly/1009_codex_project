# R21 · 地球、区域与人物之间的连续镜头

用户要求继续打磨地球到新疆、再到具体地点的自然过渡，让地理引导与人物故事连成一条线。声音继续按“先把画面做好，旁白稍后补”处理；12条待补导览未生成，原MiniMax声音文件未替换。

本轮改动：

1. 地球保持固定比例并渐隐，同经纬度的地表窗口逐渐展开为新疆高程；取消地球缩小穿过地形的画面。球面展开仍为显示变换，不是地球几何变化。
2. 从同一个区域镜头继续靠近地点，保留居中的定位点；地图末帧与局部首帧重叠过渡，局部镜头连续落到最终观察位置，抵达后不重新起步。
3. 同一坐标的区域与局部也有进入镜头，例如冰谷、喀什集市与关口。人物故事发生前先建立地点，原地的选择与回应继续保持连续。
4. 从人物场景拉远回到区域，再进入下一处；西迁与最后回望重新回到地球。每次定位配有针对该地点的引导，解释为什么从这里来到那里。
5. 定位时保持故事时间，人物的需求、选择与对白从抵达后开始；暂停同时保持定位镜头，继续从原位置接上。
6. 镜头按实际渲染的动画时间累计，页面卡顿或手动暂停不会跳过靠近地点的过程。候选版本发现的问题、局部录像与源码另行保留，最终源码与完整录像对应。

地形、影像、文化与历史依据沿用项目已有来源记录。不同地点不声称共享同一条实测水系；定位是案例背景，生活与公共协作是原创教学表达。
