# 2026-10-11 过程素材去重与恢复验收

依据用户授权，将同一素材只保存一份，保留每轮的截图、视频、未采用版本与源码记录，后续按增量保存。没有以文件名或画面相似度删除版本，而是按原始文件内容的 SHA-256 合并完全一致的内容。

| --- | ---: | ---: |

| 总库实际文件数据 | — | 13.266 GiB |

过程资料减少约 **18.949 GiB**。整理前包含工作目录普通文件和完整 ZIP 的实体副本，整理后按唯一 NTFS 文件身份统计，共享入口只计一次，包含共享库元数据。这里统计文件数据，不等同于含 NTFS 元数据的卷已用空间。

当前过程目录的入口文件逻辑大小约 21.0 GiB，总库约 24.0 GiB；同一内容通过硬链接出现在多个轮次及素材库中，文件夹属性可能重复计数。这些入口不是多个数据副本。使用 `python tools/process_store.py measure` 查看按唯一文件身份计算的结果。

## 保留范围

- 19 个已有轮次目录：R05—R23，各有独立 `retention.json` 与 `STORAGE.md`。更早已有的截图、说明与源码版本亦保留在原资料及旧归档的成员记录中，没有补造缺失的早期源码或录像。
- 7,464 份普通文件记录，包含整理期间新增的保存清单及其文件；其中 4,546 个媒体入口。路径和内容核验通过。后续仅更新过程根 README 的存储说明，其旧版本也保留于内容库和 `root-records` 快照中。
- 24 个原始 ZIP 的 12,981 个成员记录，所有成员内容均完整导入。每个旧容器 SHA-256、成员 SHA-256、ZIP 时间、压缩类型和属性保留；容器本身以 `.archive.json` 替代。
- 232 个当前网页发布文件的 SHA-256 与整理前一致。天池、冰川、雅丹数据、人物动画、声音和故事代码未修改。
- D 盘原有 R15—R19 及一个检查点的目录，通过原目录联接到 F 盘共享视图；旧素材路径仍可读取。没有再次保存一套独立的 D 盘视频。

共享对象只读，未改变的内容直接复用同一文件。实时 `web/` 与历史内容保持独立，避免后续开发改变旧轮次。运行中的预览服务曾将日志写入 R21 目录，导致文件锁；已仅重启本项目的已确认预览进程，并将后续日志改到 `web/.cache/runtime/`。历史日志原始内容保留。

整理期间检测到外部归档的 ZIP 同时被转成 `source-and-materials-retained/` 保存清单。首次应用检查在任何删除之前停止；随后核对清单内成员与已经导入的原始成员一一一致，纳入 38 份新记录，再对当前原件和替代视图完整校验后应用。新增记录没有被遗漏。

## 实际恢复验收

1. 通过工具恢复完整 R23：602 个原始文件的大小与 SHA-256 全部一致，另核对新增恢复清单。截图、完整影片、母片、声音、源码与检查记录均包含在内。
2. 通过工具重新导出真实影像检查点：101 个成员的名称和 SHA-256 全部一致，ZIP CRC 检查通过。重建 ZIP 的压缩容器校验值可与旧 ZIP 不同，成员的原始字节不变。
3. 恢复测试副本与导出的检查 ZIP 已删除，只保留验收结果，未再次留下重复素材。
4. 七项集成测试通过：相同素材复用、同名不同版本保留、可独立编辑的恢复副本、整轮导出与恢复、无变化轮次新增数据为零、源文件修改与删除的增量记录、损坏对象阻止交付，以及共享入口的唯一文件计量。
5. 总库索引同步、15 项目检查、新疆演示检查、修改空白检查通过。当前网页入口、人物脚本与冰川影像请求返回 200。

## 后续默认做法

操作说明见 [共享素材与增量保存指南](../README.md)。每轮只添加本轮新截图、录像和检查结果，并使用 `save --base ...` 冻结实际使用的源码；未改变的来源影像、模型、音频与源码复用已有对象。仅在独立交付时使用 `export`，不再运行历史累计打包脚本。规则已写入根 `AGENTS.md`、研究指南和每轮存储说明。

备份对象和清单，不要再把全部硬链接入口复制成多套独立文件。

## 核验文件

- `inventory-complete-before.json`：包含外部归档的完整原始盘点。
- `apply-plan.json`、`apply-plan-reconciled.json`、`apply-actions.ndjson`、`apply-result.json`：计划、并发记录合并及实际替换日志。
- `import-verification.json`、`preservation-verification.json`：内容库、普通文件、媒体、网页与旧归档的校验。
- `actual-recovery-verification.json`：R23 整轮恢复与旧 ZIP 实际重建的逐文件验收。
- `round-navigation.json`：19 轮清单入口。
- `unused-view-cleanup.json`：去除 3,371 个未使用的链接入口及空目录，删除的数据内容为零。
- `preview-log-migration.json`：仅本项目预览服务的运行日志迁移。
- `size-after.json`：唯一文件计量、入口逻辑大小与卷剩余空间。
