# R60 · 画面介绍与可操作的观察顺序

本轮回应“画面的介绍感还不够”。改动集中在三条历史路径的介绍层，保留现有三维场景、人物、材质、语音、自由镜头和返回地图。

## 画面变化

每幕在地图上直接交代当前地域、背景问题与简短介绍，并显示读图图例。张骞、西域都护、锡伯西迁各三幕，共九组介绍，沿用已有史实与资料范围，不增加新考证结论。

原来的“看全局、看变化、看局部”改成与内容对应的观察步骤，例如“认山地、看盆地边缘、找东侧参照”与“看交流网络、定位喀什、近看货物交接”。这些按钮调用同一故事控制器，改变实际镜头与地图进程，并保持暂停；不会自动进入模型。

地点标签同时说明该地点在这一幕里的作用。字幕下方增加下一幕入口；最后一幕先定位地点，已经定位后继续进入地点介绍，模型仍由用户主动打开。完整资料继续可展开，返回地图保留历史进度。

原 MiniMax 段落字幕按句切换，每句不超过48字。段内时间按文字长度估算，未进行逐字语音对齐；原音频、时间段和完整讲解不改动。手机默认展示紧凑标题，可点“读本幕介绍”展开正文和观察步骤，给地图留出操作空间。

## 记录

screenshots 包含修改前、候选布局、张骞背景与过程、西域都护，以及手机介绍展开前后的实际画面。checks 保存浏览器状态与自动检查。已修正手机介绍过高、最后一幕重复定位而无法继续的问题。

这次加强的是介绍与引导，不新增写实模型、高分辨率影像或历史复原。原有世界入口与区域地图能力继续保留。

以 round-59 为基底，通过 process_store.py save 按 SHA-256 增量保存本轮源码与截图。预览与网页记录用硬链接共享；不制作累计影片，不复制旧语音和视频。
