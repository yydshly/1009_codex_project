# R57 · 让故事讲解、地图变化与模型回应相连

这轮从“讲解在侧栏、模型另起一段”的断点入手，给张骞出使、西域都护与锡伯西迁补上背景、发生、影响三幕。新增九段 MiniMax 普通话旁白，合计185.724秒；字幕读取音频原始时段，地图使用同一播放进度。用户主动播放，可暂停、静音、选择章节和拖动进度；切换路径或进入地点会停止原讲解。

每幕交代历史问题，并指明画面中正在发生的变化。球面符号缩小，机构各组成与聚落、交换、水利符号分段出现。三条路径仍使用同一地球表面；进入地点与模型由用户选择，保留自由环视和直接返回地图。

集市的织物、补给、器物，家庭的安顿与引水，以及结构中的内外联系，都把实际完成的观察带回历史地图。结果解释不在点击时提前出现。西域都护结构增加12秒可暂停、重置的外侧→入口→通道→内部→返回演示；它解释空间联系，不复原行政流程。

这仍是可操作的教学原型。历史地图使用地域参照与概念符号，集市和家庭是原创教学情境；近景模型不是遗址复原，地球与独立模型没有全球连续LOD。历史依据与完整讲解保留在页面折叠区。旧场景、影片、声音和原视频继续可访问。
