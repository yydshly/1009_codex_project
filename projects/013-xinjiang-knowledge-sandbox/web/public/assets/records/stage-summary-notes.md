# 新疆3D平台阶段总结与后续指导

已有能力、当前问题与待实施方案分别阅读；原视频与现有演示继续保留。

## 最值得复用的价值：从整体到细节，用条件与过程理解地方

本次研究最大的收获，是一条可复用的认识与开发顺序：先建立位置与尺度，再解释自然差异，随后理解人文联系，最后走进具体地点观察。宏观介绍不止定位，还要为进入下一层提供理由；地图、数据、事件与3D模型共同展示条件、过程和结果。

- **全球认识**：地球、五带、国界：建立位置与尺度。 它在哪里，范围多大，与周边怎样相连？
- **自然条件**：西风、温度、降水、地形：理解地区差异。 这里有什么条件，为什么不同地方呈现差异？
- **人文联系**：丝绸之路、历史、宗教、地域特色与景点：进一步认识地方。 谁在何时行动，怎样交流、生活并形成地方特色？

- **已经实现**：R90可控探索原型：地球与新疆定位、真实DEM和部分局部影像、15个场景，张骞／都护／西迁／冰川四主题52幕，讲解字幕、选择回应、自由操作、暂停接管、返回地图与观察恢复。
- **参考内容**：参考原视频的整体定位、地理专题、历史与地点案例、多种3D解释形式及逐层引导。研究的是可见呈现与组织方法；原产品GitHub源码、完整内部架构与精度未确认。
- **研究意义**：留下可控制的探索基础，更明确后续应先设计认识问题、证据和地图层级，再制作模型与表现。验收应看用户能否说明位置、差异、联系与前后变化。
- **扩展方向**：先补区域／河谷、县域／历史聚落细图及有出处的事件过程，再补五带、气候与人文专题。其他地域复用操作和节点规则，换当地资料与关键问题，不照搬新疆故事。
- **开发指导**：认识问题 → 资料与尺度 → 每屏对象与可见变化 → 用户操作、进入理由及返回状态 → 一条完整样板 → 静音与理解验收 → 表现精修与增量归档。自动导演与自由探索共用同一内容状态。

完整五带、气候专题、区域与聚落细图及通用地域框架仍待建设；真实地表与解释模型分开。自然条件提供背景，历史与文化还需制度、交流、技术和人的行动等独立证据。

| 入口和操作已经过收拢 | 仍需检查不同窗口的信息遮挡、标签层级、人物材质和声音节奏。 | 同一套视觉语言；当前地球分色和国界已可见，其他近景需逐项复验。 |

- 价值基础：已经做出一个能操作、演示、保存和恢复的探索原型。
- 主要短板：知识组织、可读的中间地图、资料充分的事件过程；不能仅靠再加动作和语音解决。

## 价值思路与表现取舍

最大的收获是从整体到细节、从全球位置到自然条件再到人文联系的认识路径；地图与3D展示条件、过程和结果，让用户主动观察。

| 用户得到什么 | 哪些画面有价值 | 怎样验证 |
| --- | --- | --- |
| 位置与尺度感 | 球面定位、范围、邻近关系、逐层地图与可返回来路。 | 用户能在上层地图找到刚看的地点。 |
| 地区差异的理解 | 同地点专题切换、同口径数据比较、地形与流向对应。 | 用户能根据图例说出哪里不同及依据。 |
| 历史与人文过程 | 分时地点、资料支持的网络与行动、前后状态对照。 | 用户能说清事件发生在何时何地，怎样变化。 |
| 自主探索与观察 | 选点、暂停、改变观察角度、查看资料、保存结果。 | 静音也能操作；接管和返回不会丢状态。 |
| 可持续扩展 | 地图、专题、节点和素材按统一约定组织，第二地域复用操作。 | 换地域时替换内容资料，共用控制保持一致。 |

- 3D适合空间关系、结构剖面与过程；图表适合数值、年份和比较；图片与文字承载史料。按问题选择形式。
- 美术和声音帮助注意与沉浸，不能替代认知路径和证据。
- 教育或商业成效仍需用户验证：功能检查、影片长度和幕数都不是学习价值的直接证明。

## 全球认识：先建立位置与尺度

问题链：地球是什么尺度 → 地域在哪里 → 周边是谁 → 为什么靠近这一地区。

| 内容 | 画面与操作 | 所需依据与完成条件 |
| --- | --- | --- |
| 地球与大陆海洋 | 旋转后标签分级；选地域时范围突出，镜头跟随同一目标靠近。 | 范围与地名有来源；地球到全域始终能辨认目标。 |
| 五带与纬度 | 球面带状图、界线与图例；选新疆可读其纬度位置。 | 完整五带按定义表达，不能把35°—49°观察带叫五带。 |
| 国家与地区 | 大洲、国家、地域使用不同标签层级；国界可开关。 | 边界来源与表示范围清楚；现代定位和历史范围分别表达。 |
| 尺度与距离 | 由地球进入全域、保持周边；距离信息与实际地图对应。 | 操作时不失去方向；返回恢复上层选择与视角。 |

- 当前已有地球、国家范围与分级标记，后续应沿用。
- 全球层负责建立坐标，不把所有细节塞进一个地球画面。

## 自然条件：用数据和机制看懂差异

问题链：现象在哪里 → 有什么差异 → 用什么资料比较 → 哪些机制参与形成。

| 专题 | 应出现的变化 | 资料与表达边界 |
| --- | --- | --- |
| 西风与水汽 | 球面方向和流动示意；靠近区域后对应山地、河谷和观察点。 | 概念动画不冒充实测气流；季节和天气条件采用资料说明。 |
| 温度与降水 | 带时间、单位、图例的数据图层；同口径比较区域，可与地形切换。 | 取得对应统计时期的数据，缺测保留空缺；个别天气案例不推成全年规律。 |
| 地形与水系 | 全域看格局，区域看坡谷、河流与地点；必要时用剖面或流向模型。 | 高程、影像与水系匹配位置、精度和时间；每层确有新增细节。 |
| 冰川、湖泊、绿洲与雅丹 | 进入实际地点，观察形态与资料支持的过程，再返回区域比较。 | 真实观测、形成示意和参数实验分别标识；无单位试验不当作预测。 |

- 观察顺序可以从现象追问机制，再返回地图比较，形成可往返的认识过程。
- 地理条件提供背景；历史、制度与文化还需要各自的证据，不能用自然条件包办解释。

## 人文联系：用真实地点与过程认识地方

问题链：何时何地发生了什么 → 谁参与、为何行动 → 地点如何相连 → 带来什么后续变化。

| 主题 | 对应画面 | 防止混淆 |
| --- | --- | --- |
| 丝绸之路与交流 | 多个地点和通道形成网络；可选节点看补给、交换与地方环境。 | 交流网络与某位人物的具体行程分开；路线精度由资料决定。 |
| 重大历史事件 | 时序推进改变地点、路线或对象；选择节点再进入适用的活动场景。 | 张骞、都护、西迁各有时间与过程，不套同一人物和模型；现代参照不冒充遗址。 |
| 宗教、文化与民族 | 以具体遗址、建筑、文物、社区或活动为入口，显示时期和空间联系。 | 地方、时代与人群差异需来源；不以单套服饰代表所有群体。 |
| 经济与治理 | 在交换、生产、补给、安置等有资料的活动中，显示需求、组织和结果。 | 机制实验与历史结论分开；匿名人物动作不冒充具体人物真实言行。 |
| 特色与景点 | 从问题进入地点，观察形成、用途或文化含义，并回到所属区域。 | 景点不是孤立模型陈列；说明和活动应对应地点事实。 |

- 故事的主线可以是一个认识问题，不必强行拼成跨年代连续家庭戏。
- 介绍对象要在画面中发生变化：地点高亮、路线逐步出现、设施分期、对象行动和结果可见。

## 三条轴共同工作，形成一个可操作平台

认识顺序、空间层级、时间与主题各有作用，不能混成一条固定影片。

| 轴或记录 | 需要保留什么 | 决定哪些变化 |
| --- | --- | --- |
| 认识问题 | 当前想理解的位置、差异、联系或活动。 | 介绍顺序、重点标注、可选下一步。 |
| 空间层级 | 地球 → 全域 → 区域 → 县域或历史聚落 → 地点；共用稳定地点编号与上层关系。 | 地图数据精度、模型落点、进入视角与逐层返回。 |
| 专题与时期 | 地形／气候／历史／文化；每层记录适用时期、来源和图例。 | 保持地点切换专题，分清现代定位和历史过程。 |
| 事件节点 | 时间、地点、参与者、行动、前后对象状态、结果与资料。 | 路线、标记、模型、字幕和语音同步。 |
| 操作与导演 | 选择、镜头、暂停、节点进度、来路快照、个人观察。 | 用户自由看与自动带看共用内容；保存与返回可复原。 |
| 资源与证据 | 独立数据范围、精度、许可、共享素材地址与使用状态。 | 按需加载，离开释放；同一素材保留一次。 |

- 当前地球与全域、地点场景已连通；区域／聚落的独立数据和通用多级返回仍是建设重点。
- 示例关系：在区域图选地点 → 选专题或历史节点 → 看对应变化 → 主动进入场景 → 返回仍保留地点与来路。
- 这套共同记录与地域注册是后续架构目标；现有固定数组和地图快照需要整理，不能宣称已是通用地域引擎。

## 当前问题怎样变成下一阶段任务

依赖顺序：先确定知识主线和资料范围，再打通空间，随后补专题、事件、导演与美术。

| 问题 | 具体优化 | 可观察的验收 |
| --- | --- | --- |
| 整体认识路径仍不清楚 | 以全球—自然—人文组织主题，给每段写问题、前提、地点与下一步理由。 | 用户知道当前理解什么、为什么进入下一层。 |
| 中间地图缺独立细节 | 先选资料较好的区域，补区域与地域细图、共同地点和逐层返回。 | 每层新增真实可读对象；模型在上层有位置；保存刷新后可复原来路。 |
| 自然专题薄、比较不足 | 补完整五带；气候接同口径数据；地形、气候与机制按同地点对应。 | 有图例和日期，能对照两个区域；概念与观测清楚区分。 |
| 故事中间过程概括 | 把事件拆成有出处的时空节点，匹配地点、路线、设施和人物活动。 | 静音能看懂行动和前后结果；无法确认的道路或聚落显示范围。 |
| 介绍形式重复、信息易挤占画面 | 每幕明确一个观察对象；选择点线、专题图、剖面或场景；统一标签与面板。 | 必要对象可见，标记不遮挡，换专题不丢位置。 |
| 近景质感、人物年代与声音欠统一 | 达到内容和空间条件后，再按观察距离处理材质，按年代证据做服饰建筑，同步混音。 | 材质清楚但不虚报精度；人物和设施不跨年代混用；字幕声音动作对应。 |
| 复用与资源控制不完整 | 整理地域、专题、节点与资源注册；地图细节按需加载；沿用增量素材库。 | 第二地域共用操作；反复进出后资源占用稳定，无重复整包。 |

- 下一轮可用伊犁—察布查尔地域作为空间样板：复用已有西迁和安置场景，先补两层细图及返回；具体历史村址仍需证据。
- 随后用冰川线索检查不同类型能否复用，再扩展其他历史和文化专题。样板是验证方法，不是整个产品的唯一主线。
- 阶段归档可保留当前探索成果；后续按上述依赖继续，避免以局部精修代替整体收敛。

## 下一次怎样向 AI 下发同类开发任务

每个任务都给出“认识目标、资料、画面对象、操作、完成条件”，先交付可操作的完整路径。

| 步骤 | 下发内容 | 交付与通过条件 |
| --- | --- | --- |
| 1 定目标 | 地域、受众、三到五个核心问题；推荐全球—自然—人文的认识顺序。 | 一张知识与空间总图，说明各主题关系及优先范围。 |
| 2 查证据 | 范围、地形、气候、事件、地点、素材；记录来源、日期、单位、精度、许可和未知项。 | 可用／待补／仅示意的资料表；展示范围与资料相符。 |
| 3 写逐屏约定 | 每屏填写：问题 → 尺度与时期 → 地点与对象 → 可见变化 → 用户操作 → 下一层理由 → 返回状态。 | 草图与逐屏清单，文字、路线和模型有对应对象。 |
| 4 先连完整路线 | 复用已有操作；做通地球定位、全域、一个区域、一个地点与返回。 | 真实网页可选可看可返回；先解决结构再扩大内容。 |
| 5 接真实内容与过程 | 图层用真实资料；事件节点按出处；解释模型明确表示范围。 | 每次推进产生可见变化；不编造准确道路、布局或人物言行。 |
| 6 统一控制与声音 | 自由探索和导演读同一节点，定义缩放、暂停、接管、续播和保存行为。 | 手动与自动到同一节点显示一致；静音仍可读懂。 |
| 7 验收与归档 | 按实际路径操作，检查认识、证据、视觉、控制、性能与兼容，保存增量证据。 | 用户能回答位置、差异和前后变化；旧入口正常；资源占用按目标设备测量。 |
| 8 检验扩展 | 把第二个地域的内容包接入相同控制和状态。 | 进入返回、字幕与导演共用；特殊现象按问题另做表现模块。 |

- 任务模板：为【地域／受众】解释【问题】；在【尺度／时期】用【有来源的对象】表现【前后变化】；允许【操作】；按【实际路径与理解问题】验收；保留【旧能力与增量记录】。
- 每轮报告实际接入的能力及缺项。新增幕数、镜头、语音或模型不能独自代表完成。
- 先明确知识和交互的关系，再确定画面；不要只下发“做得更丰富、更像原视频”。

## 怎样扩展到其他地域

复用平台规则；重新研究当地问题、资料与故事。新地域可能需要新的现象表现。

| 复用或准备项 | 具体内容 | 判断是否完成 |
| --- | --- | --- |
| 共用能力 | 球面、相机、选点、专题切换、节点推进、导演控制、字幕语音、返回、保存和资源管理。 | 第二地域使用同一套操作与状态约定。 |
| 地域位置包 | 完整范围、下属区域、关键地点、上层关系、年代与定位精度。 | 能从地球进入全域与具体区域，再逐层返回。 |
| 自然资料包 | 地形、影像、所选气候或水系数据，时间、单位、口径与图例。 | 区域图有适当细节，比较数据可比。 |
| 人文故事包 | 事件、文化、景点或生活案例；时间、地点、行动、结果与来源。 | 能显示资料支持的过程，古今参照分清。 |
| 表现与素材包 | 对应场景、对象状态、图像、音频、字幕、许可、真实或示意标记。 | 每个模型解释当地具体问题，素材共享不复制整包。 |
| 先做一个完整案例 | 地域定位 → 一个自然问题 → 一个地方案例 → 地点观察 → 返回与比较。 | 静音和自由操作均可理解，再扩大专题与覆盖范围。 |
| 特有能力按需新增 | 例如沿海选题可能需要港口或潮汐表达，山区选题可能需要坡地或水系表达；先研究再选择。 | 新模块有明确问题与资料，可独立接入，不复制另一套导航。 |

- 新疆的认知顺序可借鉴，具体重点、史实和视觉不能直接搬到另一个地域。
- 当前尚不能输入一个地域名称就生成完整产品；用第二个地域验证复用结构之后，才扩大规模。
- 资料不足时保持适当尺度，不用宏观贴图冒充精细地图；同一文件和素材只存一次。
