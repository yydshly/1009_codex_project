# R52 · 新疆仍在地球表面，分析视图按需打开

用户指出默认地球入口直接换成切割型新疆模型不合理。本轮只修正这项空间与表示的关系，保留旧地图、历史分析、地点模型、人物操作、声音与影片。

## 最终行为

- 地球靠近新疆始终使用同一个球面。区域影像与有限DEM网格按经纬位置贴在地球表面，周边全球影像继续保留，没有侧壁或模型底座。
- 默认全域地图与地点定位使用地理空间；四主题、选对象、看周边与图鉴可操作。用户主动选择地形分析后，才切到原分析工具。历史分析也明确标出表示变化。
- 地点先在球面定位，再由用户打开模型。返回恢复原地点、球面镜头；地形分析与球面分别记住本次视角。
- 靠近可取消，自由拖动会终止自动到达。球面近景约束相机在地球外，旧工作台视距不再把返回镜头推远。
- 新区域层一次构建并复用；没有新增纹理、声音或影片副本。

## 数据与边界

沿用`assets/data-sources.json`中的NASA全球/500米区域影像与新疆DEM。球面网格193×129顶点、49152个三角面；显示高程6倍夸张，保留负高程，原始数据不改写。DEM范围外不沿边缘夹取高程，仍保留全球球面与完整显示轮廓。边缘羽化不是新增地表数据。

固定区域叠层不是全球高程瓦片流式加载、任意尺度连续LOD、实时影像或正式行政地图。历史、教学线、简化模型的原表示边界继续保留；本轮没有完成整个平台的写实资产与历史深度。

- 从地球点击靠近：到达新疆后`mapSurface=globe`、`regionalSurface=true`，同场景无地形块淡入。04—06与14—15截图分别保存入口、靠近、到达、最终全景和周边。

- 球面吐鲁番→地下水路模型→返回：地点、镜头和目标坐标完全相同，见`checks/model-earth-return.json`；水路场景实际加载，见10。
