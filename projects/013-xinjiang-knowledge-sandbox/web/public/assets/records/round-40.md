# R40 · 在地图中读懂背景、过程与影响，再走近地点模型

继续建设可控制的3D平台。地球 → 新疆整体地图 → 主题与历史事件 → 地点 → 模型 → 返回原地图，原14个场景、参数、镜头、配置、探索记录及已有声画素材保留。

## 本轮实现

- 张骞事件先显示山地、盆地、灰色教学通道与绿洲补给点；运行过程时金线延伸，放大的队伍携带货物前行；影响阶段出现交换台、货物移动、接货人物和多方向联系。跨时期网络不写成一次出使的即时结果。
- 西域都护事件从已有地方聚落与联系开始，机构建筑逐步展开，再出现往返传递物件的人员与连接。原结构模型仍可展开屋盖、选择空间。
- 锡伯西迁以小地球交代全球方向，再到伊犁抵达参照，随后住处、田地和家庭展开。安置与后续水渠分时出现：80%时住处已出现，水渠尚未展开；100%才显示后续引水。
- 三阶段各有画内标记，对应实际3D变化对象。点击标记或“靠近变化位置”调整镜头，过程标记随队伍移动。下一步运行变化后停在观察阶段，可随时暂停、续播、倒退或直接选择阶段。
- 地点卡说明“为什么来到这里”和“接下来可以探索”。进入模型前先靠近选定地点，保留位置与路径提示，再通过画面过渡进入模型；“保持当前地图”或自由镜头可中止，不会随后自动跳入模型。
- 模型卡优先显示实际人物回应。集市选择织物后，物件交接并成为孩子的披裹，家人点头；原操作面板、定位小地图、改选地点与返回保留。
- 返回恢复原主题、选点与镜头。切换事件后，若原选点与新事件无关联，清掉旧选点和局部镜头，回到新事件全图。

## 来源与表达范围

沿用[R38地理底座与来源](../round-38/README.md)及[R36历史依据](../round-36/README.md)，未新增历史事实、影像、高程、音频或影片。新增文件event-reading.js用于把已有阶段内容映射到画面对象与地点探索问题。

区域节点为现代地域参照。张骞线是盆地南缘教学廊道，吐鲁番为工程与生活延伸案例；小地球仅表达西迁全球方向，不表示完整逐站行程。人员、驮运物、建筑、聚落和家庭都是图标化原创教学模型，非等比例、非遗址或真实社区复原。

尺度过渡采用定位、镜头靠近与保留上一画面的缩放渐隐，仍未实现全球连续地形分级加载。地形与文化资产精度沿用原版本。本轮完成交互逻辑和空间阅读，不宣称已经达到原视频的资产质感。原产品源码仓库、引擎、版本与许可证仍未确认。
