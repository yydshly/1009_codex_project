# R62 · 在联系中认识新疆

本轮调整探索入口与地图的空间组织。三条历史主题分别显示交流廊道、机构与地方、跨区域起讫；用户先看完整联系，再靠近新疆、选择地点，观察关联模型预览后主动进入场景。旧区域链接接入连续地球空间，已有地形分析、自由镜头、模型与故事讲解继续保留。

## 具体变化

- “探索总览”统一进入联系地图；旧 `stage=region` 链接接入同一入口，明确切换到地形分析时仍保留独立区域模型。
- 张骞主题增加东侧方位背景，保留盆地廊道、喀什交换及吐鲁番用水两种地点入口；线条不表示张骞的逐站行程。
- 都护主题展示天山、盆地、轮台与两侧地方符号的联系；不绘管辖边界，不把现代点位当成乌垒遗址。
- 西迁主题在同一地球上显示盛京方向与伊犁，随后靠近河谷、察布查尔与家庭场景。
- 标注区分周边方位、地理骨架、地点作用与选中目标；增加横向避让和引线，减少相邻标签互相遮挡。
- 地点级别复用已有贴地模型做静态预览，进入模型前说明观察问题。返回联系地图恢复主题、地点、层级及本次会话的地图视角。
- 地点交接页收拢重复介绍及跨主题入口；故事播放仍调用原有声音、字幕与事件变化。

## 表现边界

本轮修正入口与空间联系，不宣称完整重建原产品。复用已有影像、高程、历史资料与教学模型，没有新增写实近景资产、全球连续高程加载或考证行程。地图微缩建筑是关联模型预览，不能理解为按真实尺寸复原的历史建筑。窄屏仍需滚动操作区查看详细内容。
