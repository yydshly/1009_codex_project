# R73 · 让自动导演按认识顺序推进

日期：2026-10-13。继续编辑web，以round-72为源码基底；既有冻结轮次保持只读。

## 发现与修正

原导演地球只有一幕；开场区域地图复用自由探索的模型预览，提前展示长期交流或安置结果，再回到历史背景。张骞过程与影响之间、西迁抵达与安置之间还插入地理幕，讲解顺序被打断。本轮按产品的认识层级整理三条导演：大陆方位 → 中国与周边 → 新疆范围 → 新疆地理 → 历史背景、过程、影响 → 地点 → 模型观察 → 返回地图。

- 三个地球观察幕调用现有地球图层与不同镜头。中国幕突出中国范围，新疆幕重新突出新疆；同一球面继续靠近区域。
- 区域开场只辨自然地理与现代地点，不提前显示历史路线、机构、商队或安置模型。三条线分别对照盆地边缘、天山南侧、伊犁河谷。地理模式也不再构造随后隐藏的商队和路线对象。
- 历史三段连续运行，既有MiniMax讲解与字幕继续驱动实际事件变化；事件结束等待当前镜头完成，随后才进入地点。
- 顶部保留五个认识层级，可直接选层；下方原幕次、暂停、续播、切路径、自由接管和回地图保留。说明按需展开，画面观察线索与字幕仍可见。
- 事件与模型标注增加左右避让。原标注只尝试上下移动，盛京方向容易被导演说明卡挡住；改为绕开说明区域，用引线仍指回原地点。
- 暂停时选择新疆地图，立即显示该幕的地理状态，不先露出上一版的历史结果。自动导演入口跟随当前探索路径；网页刷新仍只打开入口，不强制播放。退出导演回地图时保留静止的联系视图，不再自动启动另一套地图引导。

## 实际验证

浏览器验证记录见browser-verification.json及本目录20张截图。三条路径均从头自然运行到结束，返回地图后停止：

- 张骞：织物、补给、器物各完成接收与使用回应，留下三个导演观察。
- 都护：入口、展开屋盖与通道连接实际运行，留下内部通行及地域连接观察。
- 西迁：出发、抵达、安置连续运行；先安顿与先引水分别产生灯火、渠水及家庭回应。
- 暂停保持时间不推进；暂停时跳到中国幕和区域幕，范围及纯地理状态正确。自由接管退出导演；再次打开跟随当前路径。退出导演返回静止联系地图，不再自动播放地图导览。
- 西迁背景幕的盛京、伊犁两端标注可同时读到；390×844小屏无横向溢出，返回地图按钮始终可见。截图15、16、18分别保留这些结果，20为正常窗口的最终入口。

主检查90项、故事播放器13项通过。check-before-repair.txt保留旧断言因顺序更新失效的首次检查，check-output.txt保存修正后的最终检查。浏览器记录为抽样状态：非当前层级的旧标记字段可能保留，判断以当前stage/layer及画面为准。07为都护历史过程加载中的截图，13为西迁模型回应结束后的返回地图，保留原取证文件名，不作为整段影片。没有新录制影片。
