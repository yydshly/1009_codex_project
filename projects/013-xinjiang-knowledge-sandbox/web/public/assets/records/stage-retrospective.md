# 新疆三维知识平台阶段总结与后续设计

2026年10月14日。当前三维运行版本停在 R90，作为可操作的探索原型保留；本次归档整理反思和后续设计依据。下一阶段以全球与区域地理认知为主干，逐步进入有史料依据的事件、文化与地点探索；多尺度地图承接这些问题，已有模型、交互、声音和素材作为可复用基础。

## 阶段成果与适用范围

当前已经连通地球定位、新疆全域认识、历史事件、地点模型和返回地图。保留自由旋转与缩放、参数与选择、暂停与接管、探索记录恢复。张骞出使、西域都护、锡伯西迁及一号冰川共有四个导演主题、52幕，已配置讲解和字幕。其他自然、文化、家庭、庭院、关口和工程场景继续可操作；它们没有全部建设独立导演或同等深度的故事。

这些成果证明了入口、对象联动和观看控制可以共用一个平台。知识覆盖仍是选取的案例，人物与建筑多为解释模型，尚未形成覆盖新疆各区域和各时代的完整知识产品。功能检查通过表示相应行为符合检查条件，不能替代内容完整性、历史考证和用户体验验收。

| 内容维度 | 已有基础 | 后续需要补足 |
| --- | --- | --- |
| 自然与地理 | 地球、区域地形、山地盆地、水系、局部冰川影像和高程 | 区域细图、县域或聚落地图、地点与周边环境的连续关系 |
| 历史 | 八段年代索引及三条较深入的历史路径 | 有出处的具体节点、时间关系、事件过程及影响延续 |
| 文化与民族 | 传习、家庭、迁徙与部分传统形制资料 | 对具体社区、时期、地方差异的材料，人物身份与活动依据 |
| 经济 | 交换、补给、生产和关口协作情境 | 对应时期的货物流向、生活需求、生产条件及可核查案例 |
| 政治与治理 | 机构、迁徙与安置背景 | 制度如何通过具体地点、组织与行动影响地方生活 |

## 参考演示带来的主线修正

用户对原演示的观察列举了地球、五带、西风、丝绸之路、地形、温度、降水、国界、地域特色、景点与宗教等内容，并认为它们的呈现更丰富、清晰。这条反馈提示：后续设计既要补齐地图精度和故事过程，也要先建立完整的地理认知顺序。这里记录的是用户观察与设计反思，不据此推定原产品内部技术或全部专题的实现方式。

现有四个导演已经能演示选定故事，但几条历史事件较早成为主要结构，全球和区域地理专题还没有形成同样清楚的学习路径。已有部分方位、地形、气流与交流入口，专题之间的认识关系和具体图像表达仍需深化。

后续主线先认识世界位置与自然条件，再比较区域差异，随后选择历史、文化或地点问题。细地图与人物行动建立在这一认识基础上；历史导演作为可选专题示范，自由探索使用相同的地图对象和资料。

| 认识层次 | 重点内容 | 应当出现的可观察变化 |
| --- | --- | --- |
| 全球背景 | 大陆、国家与地区、新疆位置、纬度与五带 | 球面分带、名称与范围分层，当前讲解对象高亮，定位逐步靠近 |
| 自然条件 | 西风等环流主题、温度、降水、地形与水系 | 风向与进程对应；温度和降水专题使用来源、时间与图例清楚的数据，可对照地形观察 |
| 新疆区域差异 | 山脉、盆地、河谷、绿洲与通道，各地环境与特色 | 全域到区域的地图展开，周边地理保留，同一地点可切换专题比较 |
| 历史与文化联系 | 丝绸之路、具体历史事件、文化与宗教案例 | 时间、地域、路线与资料对应，切换案例后对象和地点实际变化 |
| 地点与生活观察 | 景点、遗址、县域或历史聚落、设施与人物活动 | 进入有依据的具体环境，看到行动、停留、使用与结果，返回仍能定位 |

纬度分带、风向、温度、降水和国界各有不同的数据与表示范围，不能混用同一层图例或把概念动画当作观测结果。宗教、文化与人群专题需要对应地域、时期和具体材料；自然条件提供空间背景，不能单独解释其历史形成。现代国界和历史活动范围分别表达。

补充专题时先写清“用户要理解什么、地图怎样变化、下一步为什么进入这里”。这样，地域特色和景点可以成为理解地方的延伸，丰富度来自专题关系与可观察内容。

## 探索中暴露的问题

### 产品目标曾偏向制作影片

连续镜头和完整成片一度成为主要成果，用户主动认识地点、切换问题、观察变化的结构建设滞后。后续以可控制的三维知识平台为目标：自动导演演示同一套可操作对象，录像用于保存使用过程。

### 宏观地图承担了过多解释

地理、事件、地点和人物长期压在同一个区域模型上。一个标记配一段讲解能建立概念，却难以说明山口、河流、绿洲与行动之间的具体关系。人物场景独立出现后，用户也容易失去它与周边空间的联系。

需要补齐区域、县域或历史聚落、具体地点这些中间尺度。地图细化的目的，是让用户看清事件发生的位置和过程；更高分辨率的纹理只有在支持这些观察时才产生实际价值。

### 故事有起讫和结论，中间过程仍薄

“背景、过程、影响”已经形成结构，但实际过程仍有较多概括。一个事件应进一步拆成能定位、能观察、有时间关系的节点，解释行动目的、当时条件、发生的变化及后续结果。宏观联系线和通用人物动作不能独自承担这些内容。

### 局部精修先于整体设计

人物小动作、字幕、标签、镜头和声音逐轮增加，入口与介绍也曾重复。局部质量提升没有自动形成清楚的知识路径。下一阶段先确认故事、空间层级和交互顺序，再选择必要的模型与表现效果；新增动作必须对应一个需要理解的事件或机制。

### 史实、现代参照与示意场景需要持续区分

张骞记载的出使经历与后来的长期交流不是同一段行程；现有喀什集市是跨时期交换情境。现代轮台定位与乌垒研究不能直接等同，抽象建筑不表示考古测绘布局。锡伯迁徙、安置和后期水利应按不同时间段呈现。冰川真实地表观察与教学流向、无单位收支试验分别标注。

这些边界已有页面与资料记录，应作为后续内容设计约束继续保留。史料无法确认的具体道路、人物言行和建筑布局，不因制作动画而获得事实身份。

## 多尺度地图设计

后续探索顺序为：**地球 → 新疆全域 → 区域或河谷 → 县域或历史聚落 → 具体地点 → 人物行动**。六个尺度是设计目标，当前运行时尚未完整实现。

| 尺度 | 用户要理解什么 | 对应画面与操作 |
| --- | --- | --- |
| 地球 | 新疆在世界、中国与周边的位置 | 大陆和国家名称分层，新疆范围清晰，主动定位和进入 |
| 新疆全域 | 山脉、盆地、水系与主要通道的整体关系 | 保持完整地理背景，选主题、区域或事件，再进入下一层 |
| 区域或河谷 | 为什么故事发生在这里，地理如何约束行动 | 展开山口、河谷、绿洲和补给地点，对比可确认的空间关系 |
| 县域或历史聚落 | 从哪里进入、在哪停留、地点之间如何联系 | 显示适用年代的聚落和活动节点，观察到达、停留与转移 |
| 具体地点 | 事件发生在什么设施或生活空间 | 显示有依据的建筑、院落、田地或工作空间，对象可点选 |
| 人物行动 | 谁在什么条件下做了什么，产生什么结果 | 行走、停留、交流、作业及回应与事件进程同步 |

只对故事涉及的关键区域逐层展开。一个事件不必使用全部尺度，但应交代省略的空间关系。历史区域、古地名与现代县界分别显示；现代边界用于定位时注明参照年代。不能默认当代县城就是历史事件的聚落位置。

进入下一层前，画面说明当前问题、目标地点和进入理由。进入后保留上层位置提示；返回恢复主题、地点、进度和视角。地图与模型共用地点身份和空间参照，用户能看到模型在区域中的位置，而不是只看到突然出现的独立模型。

## 真实故事的节点组织

先完成资料梳理，再写导演脚本和制作人物动作。每个节点至少记录以下内容，缺少依据的字段保留未知或明确示意。

| 字段 | 需要描述的内容 |
| --- | --- |
| 时间 | 日期或时期、前后顺序、确定程度，区别于动画播放秒数 |
| 地点 | 点、范围或地域参照，关联上层地图及适用尺度 |
| 参与者 | 可确认的身份与角色；匿名人物表示活动，不冒充具体史实人物 |
| 行动及原因 | 行动目的、环境条件、组织安排，以及资料支持的因果关系 |
| 起点与目的地 | 地点间如何移动，哪些路线能确认，哪些只表达方向 |
| 过程与结果 | 到达、停留、交接、建设或使用如何改变后续状态 |
| 画面对应 | 哪个地点高亮、哪条路线变化、哪个对象或人物产生动作 |
| 资料依据 | 来源、采用段落或页码、日期、表示范围及素材许可 |
| 用户操作 | 暂停、回看、比较、点选、自由观察和返回后的保留状态 |

行走应呈现起点、目的地、停留原因和结果。史料只能支持地域联系时，使用方向或范围示意；资料支持具体路段后，再呈现贴合真实地形的行进。人物回应表达资料支持的活动结果；原创对白和假设选择明确属于解释情境。

自然、地理、历史、文化、民族、经济和政治通过这些节点交叉呈现。某地的服饰不能代表全部人群，地形也不能单独推出制度或文化。每个节点只呈现有内容与依据的维度。

## 下一阶段的开发顺序与验收

1. **先设计地理认知主线和专题。** 确认全球位置、纬度与五带、环流、温度降水、地形和区域差异的认识顺序，逐项列出资料、地图变化和进入理由。
2. **整理所选区域的证据和故事节点。** 为历史、文化、宗教和地点案例建立时间、地域、行动与来源表，确认可做的细化范围。
3. **选择一个资料较完整的区域样板。** 用已有资料评估选题，完成全域到区域、聚落、地点的尺度设计和粗略可操作地图。
4. **接通事件过程与空间。** 地点、路线、对象状态和人物行动读取同一节点进程，完成进入、停留、转移与返回。
5. **完善必要的画面和声音。** 根据观察距离安排地形与环境细节，依据年代制作人物与建筑，讲解、字幕和动作同步。
6. **按同一标准检查其他线索。** 保留自由探索和现有导演，逐条补足证据与空间，不以新增幕数作为完成指标。

样板验收应观察：用户能否指出当前地点及其周边，能否说明进入下一层的理由，静音能否读懂行动与结果，返回能否保持来路，导演暂停与自由接管是否稳定，历史陈述是否能回到具体来源。数据缺失的地点保持相应精度，不通过放大宏观纹理宣称已完成聚落细图。

## 如何指导 AI 开发同类项目

把目标写成可检查的用户体验：用户从世界位置认识一个地域，比较自然条件，选择历史文化问题，逐层进入具体地点，再能返回原地图继续观察。完整录像是探索过程的记录，完成标准是这条路径可以自主操作、能解释内容并保留来路。

每次任务先明确目标用户、已有基础、这次范围、要理解的问题、参考效果和验收条件。参考演示按片段记录其位置尺度、知识问题、对象变化、用户操作和下一步关系；只从录像能看到的行为提炼设计，不把猜测的技术写成需求。

### 给 AI 的必要输入

- **产品目标与范围。** 写清认识路径、允许自由操作的对象、本次要贯通的样板，以及继续保留的已有线索。
- **内容与证据。** 提供地域、主题、事件、年代、地点和资料清单。每条陈述对应采用范围，未确认项保留为待研究。
- **画面与交互要求。** 指明讲解对象、地图图层、尺度、可见变化和返回行为，附参考片段或同视角截图。
- **环境与资源条件。** 明确设备和窗口、运行方式、可用数据与素材、下载和生成预算；性能目标在目标设备上测量。
- **验收与记录。** 定义静音可读、暂停可观察、自由接管、返回恢复、资料可查及增量保留要求。

### 分步产出和检查

| 开发阶段 | AI 应交付什么 | 检查重点 |
| --- | --- | --- |
| 内容设计 | 认识问题、专题顺序、节点与证据清单，已有和缺失内容 | 能否解释每一步的意义，事实与设计是否分开 |
| 空间设计 | 地球、全域、分区、地方和场景的对应图，进入与返回规则 | 地点是否有周边关系，尺度变化是否有理由 |
| 可操作样板 | 一条从全球到地方再返回的完整探索，地图与对象同步 | 自由操作和导演是否使用相同对象，状态是否连续 |
| 画面与声音 | 当前观察距离需要的地形、环境、人物、标记、讲解和字幕 | 视觉焦点清楚，静音可懂，时代与资料范围一致 |
| 扩展与回归检查 | 增加专题或地域，复核原样板与旧入口 | 新内容接入后，已有路径、保存和返回仍正常 |

AI 每轮应说明本轮改善了哪个用户问题、使用哪些证据、实际改变了什么、哪些检查完成及尚有哪些缺口。测试与截图记录功能和画面表现；内容是否可信、用户是否理解还需要对应的资料与体验判断。阶段检查发现结构性问题时，优先修正主线和数据关系，再扩大内容范围。

### 可复用的任务说明

为指定地域设计可控制的三维知识平台。以全球认识、自然条件、人文联系为内容顺序，用多尺度地图逐步深入分区、聚落和地点。先阅读现有实现与记录，提出本次要解决的认识问题、资料依据、空间层级和可见变化，再完成一条可自由操作、暂停、接管并返回的样板。自动导演使用同一套对象与状态。史料或数据无法支持的细节保留未知或明确示意。每轮检查原入口和保存恢复，报告目标、变化、证据与验收结果，截图、声音与源码按内容增量保存。

使用时补上地域、用户、样板问题、已有能力、目标设备和资料预算，使任务有具体边界。样板检查通过后，沿既定内容结构自主推进；关键资料缺失或目标改变时再明确调整方案。

## 如何扩展到其他地域

通用框架提供地球与地图显示、对象点选、尺度切换、自由镜头、事件进程、导演与字幕、保存和返回。各地域提供位置与范围、专题内容、观测数据、历史节点、地方场景和来源。这里是下一阶段的组织建议，当前新疆原型尚未完成通用地域配置与加载框架。

| 可以共用的能力 | 每个地域需要重新整理的内容 |
| --- | --- |
| 地球定位、镜头、图层和对象选择 | 范围、父区域、分区、地点坐标及定位精度 |
| 进程控制、导演、讲解与字幕同步 | 认识顺序、特色专题、故事、语言与讲稿 |
| 高程、影像和专题图显示方式 | 数据来源、分辨率、时间、单位、有效范围与许可 |
| 地点与模型的进入、操作和返回 | 历史环境、建筑、人物、设施与具体活动依据 |
| 观察记录、素材共享与增量保存 | 地域和对象身份、配置版本、数据更新与迁移规则 |

地域内容配置先列出地域身份、显示范围、父区域、地图尺度、专题、地点、事件、资料、素材、默认视角和适用年代。对象使用稳定身份，事件引用地点、地点引用上层区域、素材通过引用共享；更新数据时能够追溯版本，保存记录能识别不兼容的旧对象。

扩展时采用以下顺序：确认目标用户与核心问题，盘点资料能支持的精度，设计地域专题和地图层级，接入一个区域样板，检查原有地域，再扩充地点和故事。新地域根据自身材料重新组织内容；全球认识的通用入口保留，人文主题按当地时期和证据展开。

高原、沿海和流域地域可以分别从海拔与水源、海岸与聚落、河流与生产等问题评估选题。这些是选题示例，实际自然过程和历史关系须在新地域的资料中验证。选择适合内容的层级，行政县域并非每个专题的必经层；河谷、港湾、古道或遗址范围也可以成为关键分区。

### 数据和性能也要随尺度规划

为全域认识准备覆盖完整、成本较低的底图；用户进入关键区域后再加载细地形、影像和地点资产。数据精度、观察尺度、图例和模型表示范围对应，时间与单位保持可查。缺少精细资料时保留适当尺度的地图或示意，并说明可继续研究的对象。

在目标设备测量首屏加载、交互响应、切换后的内存和纹理占用；设定细节、同时显示对象及缓存的预算，退出区域后释放不再使用的资源。通用依赖与相同素材共享，地域资料按引用接入，过程仍按内容增量保存。新地域验收同时检查原地域，避免扩展后原路径或个人观察失效。

## 阶段保存与继续开发

R90 是运行能力基线，R91 是本次归档与反思记录。已有冻结轮次和共享对象保持只读；后续编辑实时 `web/` 或恢复后的独立副本，按 `process_store.py save` 保存增量。截图、影片、声音母片、候选版本、源码与校验记录继续保留，同一内容只保存一次。

Git 阶段提交保留当前源码、运行素材、设计反思和逐轮清单；完整的历史过程材料与大体积影片保留在本机共享素材库。迁移到其他机器时，还需备份共享对象库和清单，或按需要导出独立交付包。浏览器“我的探索”保存在用户本机，继续使用前可从平台导出配置；源码归档不自动代替个人记录备份。

后续接手先阅读本总结，再查看当前运行说明和证据。旧蓝图、旧影片及未采用版本是研究过程，不代表最新实现或后续需求全部完成。
