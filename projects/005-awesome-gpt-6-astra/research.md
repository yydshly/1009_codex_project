## 实验与复现

前两阶段独立实现完整样例库和研究说明页，未引入上游运行时代码。第三阶段为了展示真实背景效果，引入轨道花园的固定版本原始单文件源码，保留 README、作者与 CC0 许可，独立添加展示适配层。保存上游目录 README 原文作为构建输入；三张精选作品图片在本地，其余目录预览仍引用原始地址。

- 输入：固定版本完整目录、关键源码和所选作品的 README / 创作记录。
- 交付：175 项完整浏览、六类筛选、关键词搜索、源码入口筛选、三种排序、分批浏览、作品详情及外部试玩；独立说明页保留四项能力切换、两条四步骤原理流程、四种目标研究路径和三个精选案例。
- 验证：在本页浏览器中检查桌面与手机布局、交互切换、键盘导航、静态资源加载和编号子路径；具体结果见下方验证记录。
- 边界：没有重新运行 175 个作品，也没有独立复验上游作者的游戏测试结果。试玩进入原作者站点；本地构建无需网络，外部试玩和远程预览需要联网。原理流程为解释图；目录基于固定快照，不自动同步上游。

## 发现与结论

1. 案例合集的价值在于缩短成品、需求与实现之间的查找距离。能否复用必须逐项查看源码和许可。
2. README 驱动目录减少重复维护，适合项目索引、案例库与作品展示；动态更新依赖服务端抓取、缓存和错误回退，不是只复制前端即可获得。
3. “AI 制作”描述开发分工，不等同于成品运行时调用模型。所选作品既有程序生成画面，也有另行生成素材的路径。
4. 上游来源区分作者自述和已验证范围；研究展示沿用这种区分，避免把成品归因扩大为模型性能结论。
5. 本页的场景建议属于基于公开源码与文档的研究判断，不是上游承诺。
