## 我们的理解

Lemo-Opuscar是让编程AI用代码制作风格化短片的一套Skill／插件、风格规范和公共制片工具。用户带来主题，AI设计故事、编写动画、制作声音与字幕，再逐帧渲染导出视频。

| 层次 | 解决什么问题 | 依据 |
| --- | --- | --- |
| 风格 | 材料、色彩、笔触、字体、运动与声音，决定长什么样 | STYLE.md |
| 导演方法 | 开头钩子、目标与转折、节奏、镜头、表演和结尾，决定怎么讲 | DIRECTOR.md |
| 制作工具 | 渲染、配音、配乐、拟音、字幕、混音、导出和检查，决定怎么做 | TECHNIQUE.md、core/ |

“除了风格，还增加钩子吸引眼球”的理解方向正确。这里的钩子是由AI执行的叙事和视听要求：前三秒进入事件，故事经历变化，留一个记忆镜头，用快慢、停顿和声音组织情绪。工具能检查文字停留、配音和响度，故事是否吸引人仍需创作判断与观看评审。

## 能力、模块与原理

六类制作能力：需求组织、视觉与声音语言、导演与表演、代码画面与运动、五轨同步与声音制作、检查/导出/工程留存。

八类模块按职责整理：Skill入口，风格资产，导演与创作方案，时间与画面基础，渲染与画面检查，配音/配乐/拟音，校验与合成，官方作品展台。它们包括文本规范、每支影片的实际实现和共享脚本，不能视作同一种自动服务。

Agent按规范组织创作与写代码；画面页面声明 `DUR` 和资源就绪的 `READY`，以 `render(t)` 独立计算指定时间的帧，并使用带种子的随机数。五轨共用秒数、节拍和事件。无头浏览器逐帧捕获，FFmpeg编码并合成声音、字幕与响度。可读性、配音和响度可做客观检查；风格执行、理解度、节奏和吸引力仍需观看评审。

## 价值与可扩展方向

对当前研究总库，可将项目与原理讲清楚，将审美与导演方法沉淀为自己的表达规范，执行制片后保留可修改工程，再通过同题材试验选择适合的路线。电影题材可以换成自己的项目、产品或设备，Clawd可以换成自己的角色或物体。

| 扩展方向 | 需要补齐与验证 |
| --- | --- |
| 自有风格规范包 | 授权配色、字体、材质、动作与声音；真实风格帧、跨题材一致性 |
| 参数化场景与镜头 | 输入/坐标/时间契约、每种风格的代码适配；换材料后的结构与可读性 |
| 自有角色与系列故事 | 角色转面、表情、动作、跨材质适配；辨识度与每集叙事变化 |
| 真实模型与数据 | 来源、单位、部件语义、专业审核与导入器；画面不等于工程仿真 |
| 多画幅与多语言 | 构图重排、字体覆盖、TTS/字幕适配；阅读时间与声画落点 |
| 互动预览与成片共用 | 实时循环、离屏暂停、分辨率/GPU预算；指定时间帧与设备性能 |
| 制作与质检工作台 | 任务调度、恢复、模型和工具接入、资源隔离、台账与人工评审 |
| 版本与效果评估 | 一致实验条件与资产版本；理解度、同步、耗时、修订和观众反馈 |

上述扩展是研究建议；本页已验证的一部分是蓝图源码在网页中定点查看与播放，没有实现完整工作台或证明生产效率和传播效果。

## 我们的理解全景图

网页 `#overview` 汇总这轮讨论：OPUSCAR98 以经典获奖电影为入口，选择有辨识度的场景、道具、动作和镜头符号，让同一个 Clawd 角色出演，再重新编排风格、表演与镜头，用代码构建动画场景。整库将视觉规范、导演判断与制片工具提供给新的题材复用。

一张连续图中列出全部9类43种风格、6项约束、6类场景、4项个人价值和交付流程。蓝图原作画面作为实时模块，上游电影致敬动画和风格样片的真实静帧作为背景与案例；图中可播放样片、查看规范和整理首个任务。

网页提供PNG和SVG下载，下载版用真实静帧替代动态播放器，完整保留图中总结。保存的[完整PNG](assets/understanding-overview.png)与[可缩放SVG](assets/understanding-overview.svg)均可离线阅读；SVG内嵌作品图片。与网页共用 `overview-content.js` 内容，43种风格名称直接读取固定版本的目录数据。
