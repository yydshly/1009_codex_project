03 / DIRECTING

“钩子”，也是导演工作。

它不只规定画面好看，还要求让人进入事件、读懂动作，跟着节奏看到结尾。

从吸引注意，到留下印象

  1. 01

    前三秒：让事件发生

    明确一个主体和一个问题。观众先看到事情正在发生，再逐渐获得解释。

  2. 02

    故事：目标 → 转折 → 变化

    人物、物体或概念有一个目标，发生一次变化，结尾与开头呼应。

  3. 03

    节奏：快慢与停顿

    安排加速、减速和呼吸空间；声音在转折前留出近乎安静的片刻，再用关键声音落点。

  4. 04

    镜头：留一个记忆点

    用跟拍、推拉、尺度揭示或一镜到底，让观众看清主体，感受到变化。

  5. 05

    风格：让材料成为转场

    墨扩散到下一场景、纸折叠成空间、线条长成新物体。视觉风格直接参与讲故事。

OUR DISCUSSION / 理解校准

“除了风格，还增加了钩子来吸引眼球？”

方向是对的。这些钩子主要表现为叙事和视听设计要求，由 AI 在具体影片中执行。

工具可以检查字幕时长、配音和响度。故事是否好看、开头是否吸引人，仍需要创作判断与观看评审。

从构想到交付

  1. 01 / 确定需求主题、风格、时长、语言、声音、现有材料和是否先看分镜。
  2. 02 / 写创作方案比较三种故事结构，确定镜头、节拍、声音与结尾。
  3. 03 / 证明画风用真实绘制代码制作角色表、风格帧；按需展示关键分镜。
  4. 04 / 制作与渲染完成各轨道，逐帧输出画面，制作音轨并合成。
  5. 05 / 观看与修订查看联系表、动作连续帧，完整播放并检查声音。
  6. 06 / 完整交付MP4、poster.jpg、SRT、TREATMENT.md、CREDITS、源码与 build.sh。

哪些能检查，哪些要判断？

工具检查

文字停留与可见性、逐句配音识别、页面报错、音频完整性、输出响度。

流程要求

检查黑帧、声画同步、动作连续性；看关键帧并完整带声音播放。

创作判断

钩子是否有效、情绪是否成立、镜头是否清楚、故事是否值得看完。

有些规则写在指南中，需要 Agent 主动执行；不能仅凭成功导出视频判断创作质量。

运行环境
Node.js 20+、Python 3.11+ 或 uv、FFmpeg；上游建议 Windows 使用 WSL。3D 与复杂着色器需要 GPU。
时间与模型
作者估计一支影片约需 30–60 分钟，token 用量不小。样片按 Claude Opus 5.5 调整，换模型的效果需要验证。
默认输出
1920×1080、24 fps；可指定竖屏。中文默认 edge-tts 需要联网，离线 Kokoro 中文声音较朴素。
能力边界
主要面向新短片创作，Skill 不用于已有视频的剪辑或格式转换。指南提供创作要求，成片质量仍需观看评审。
授权与材料
仓库采用 MIT；样片第三方素材沿用各自授权。新影片通过 CREDITS 记录实际使用的素材与来源。

      
它和“输入文字，直接生成视频”的方式有什么不同？
它让编程 AI 写画面与动画代码，再按时间逐帧渲染。可控性来自代码、风格规范和时间线；修改某个镜头后仍需运行构建与渲染。声音可使用 TTS、采样与合成工具。
43 种风格，是 43 个自动套用模板吗？
每种风格提供视觉与声音规格、样片和技术参考。Agent 要为你的主题设计新故事与绘制代码；上游要求在写出自己的创作方案之后再参考样片实现。
有钩子规则，就能保证吸引眼球吗？
前三秒进入事件、节奏变化和记忆镜头是导演要求。是否有效取决于主题、构图、表演、声音和观众；工具检查不能代替实际观看判断。
“活体实机录屏”使用了实际屏幕录制吗？
